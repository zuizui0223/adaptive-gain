## Real source climate variables and algorithm

Open-Meteo Historical Weather API (https://open-meteo.com/en/docs/historical-weather-api) provides publicly accessible model-specific ERA5 historical daily output at model ~0.25°. Request in no more than seven 5-cell groups, at deliberately limited interval to respect public provider fair-use quotas. Explicit models=era5, cell_selection=nearest, elevation=nan to bypass provider DEM downscaling, timezone=GMT, wind_speed_unit=ms, daily wind_gusts_10m_max and temperature_2m_mean. Three disjoint full-year decades 1991–2000, 2001–2010, 2011–2020; 21 source decade/group requests. Require precisely matching original 0.25° model cell coordinates, actual UTC 10,958 days per cell, original m/s and C unit claims from source, complete daily records (no fabricated zeros), source raw JSON SHA256 per source request. An individual-cell JSON dict must not be mistaken for a multisite array; original Stage110 fixed this source service cardinality issue.

At each original GAM land-intersecting grid cell, use *climatological* monthly mean 2m temperature across original 1991–2020 >5 C STRICT to select putative flowering months, then over all original days in those months count daily max 10m wind gust >15 m/s STRICT. Prespecified >10m/s and >20m/s also recorded. Build original GAM source region area-weighted mean using original independent true mainland land-intersection km² of each cell, require source weather complete and flowering-eligible in ≥95% of land area; record cell min/max, weighted spatial SD and effective source land-cell count. These are physical model resolution diagnostics, not field-scale flower airflow nor formal sampling uncertainty intervals.

Every source-completed group writes a partial source receipt of complete 30-year cell climatologies and unmodified source API response SHA; if provider rate limits fail later, completed cells remain auditable but NO claim of complete GAM region is made. The full region response is published only after 33 actual native model cells and 21 complete original source decade responses have passed all source checks.

## Scientific limits and subsequent direction

A successful GAM new-block source gust proxy expands the geography-only physically source-verified ERA5-model grid proof from two to three large geographic blocks, but still not all 17 exploration blocks and not a complete 72-region 1991–2020 wind-exposure analysis. No WFO fragrance, NHM spot/stripe lexical report, true nectar guide, flower VOC production, AusTraits diameter or Bombus source observations enter this stage.

The original Stage105/107 source audit found that regional botanical floral documentation completeness is a strong climate-correlated confounder and that scent reports and diameter outcomes can change sign depending on denominator/source reporting. No previously claimed spatial wind effect can be promoted to adaptation even if wind retrieval scales successfully. Future tests need 72-region statistically principled sampled-source spatial coverage or high-resolution independent climate access, plus independent pollen guild and phylogenetic/observation correction. External original Copernicus CDS hourly 10fg corroboration is still unavailable but NOT required for this explicitly source-labelled model-derived daily physical climatology route.
