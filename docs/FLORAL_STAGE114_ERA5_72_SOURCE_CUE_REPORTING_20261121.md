# Stage114 — Original 72 mainland geographic exploration: 1991–2020 ERA5-model gust POINT × 3 floral source reports

2026-11-21 JST. Working hypothesis: stronger regional gust exposure may change the ecological accessibility of different floral cue channels (near-field floral spots/stripes, far-field flower size, flower scent and insect information learning costs), rather than simply increasing/decreasing all signals. **This source-screening method does not observe sensory cue usage order, learning cost, bee landing success, VOC plumes, fitness or floral UV guide presence**, so it cannot confirm that mechanistic hypothesis.

## Why return to the biological comparison now

Stage105 authentic source actual 33 regions (15 geographic blocks) of 1991–2020 ERA5-MODEL daily gust **one REPRESENTATIVE POINT** per region showed original NHM lexical floral marking positive per native flora raw rho +0.679, but rank-partial after NHM colour documentation coverage, WFO original full-description coverage, latitude and local temperature +0.082. NHM/WFO documentation coverage alone correlated with strong gust at rho around +0.776/+0.774. WFO floral scent positive mentions per description raw gust rho +0.677 vs scent positive share among explicitly positive+negative descriptions raw rho -0.512; these data definitions differ materially. This was a source-reporting process diagnostic, not evidence of wind-mediated sensory adaptation.

Stage107 expanded source reporting denominators to original 72 contact-free mainland exploration regions (17 source geographic blocks), but used WorldClim 2.1 **1970–2000 mean wind** as exposure, not the biologically requested 1991–2020 ERA5 daily gust exceedance. Floral marking per source native population was raw rho +0.275 and source-coverage adjusted -0.050; floral fragrance per source description +0.229 to source-coverage adjusted +0.049; positive among original explicit positive+negative source reports -0.370. These are still source-reporting observations.

Stage113 is the immediately preceding ORIGINAL source-completion step: reuse the authenticated 33 early-stage (first50 geographical) historical ERA5 point values and obtain the missing 39 original 72 geography contact-free exploration point climates for the same fixed calendar 1991–2020. It deliberately does NOT claim all72 complete 0.25° area-weighted regional winds, because Stage111 original geography audit requires ≥36,169 cells and ≥21,801 five-site×three-decade source API calls for region-independent retrieval and only WDC/DEL/CAB/GAM true full area winds (four different original regions, 69 grid cells) have genuinely been retrieved. CDS raw hourly original 10fg data also remain unavailable; this uses Open-Meteo delivered ERA5-MODEL historical daily max gust >15m/s among long-term 30-year months with mean daily T2m>5°C.

## Declared source analytical model

One observation is a geographic **TDWG3 native flora species-list region**, NOT one flower, one bee or one independent adaptive transition. Exactly 72 unique source exploration mainland regions across 17 independent-ish coarse geographic blocks; 37 original holdout floral outcomes are completely excluded and unexamined. Original evolutionary species reuse/relatedness remains an unmodelled issue.

Primary wind exposure: 1991–2020 Open-Meteo-delivered **ERA5-MODEL historical daily 10m max gust strict >15m/s** in climatological months with monthly mean T2m >5°C at original TDWG region representative point. Original strict >10 and >20 m/s thresholds are sensitivity, never a cherry-picked primary variable. No WorldClim 1970–2000 mean-wind proxy replacement.

Separate source outcomes with explicit denominators (all are *documentation metrics*, not observed real sensory phenotypes):
1. **Near visual** NHM plant floral spot/stripe WORD-positive source / all WCVP native source species; separately per NHM flower-colour-documented native source species. An unmentioned guide is UNKNOWN, not guide absence.
2. **Chemical** WFO flower scent lexical positive source mention / all original WFO full flora botanical description species; separately positive/(explicitly positive+explicitly negative scent botanical reports). WFO scent descriptions are not independently verified VOC emission or true olfactory far-field/receptor values; the two denominators answer different selection/observation questions.
3. **Far visual** AusTraits v7 actually source-labelled flower_diameter regional median, with true measured-source n≥3 and separately n≥10 species. This median is computed using species-level pooled original source values repeated across their native TDWG regions and is not an independently recorded field population size. WFO 212 source interval/upper/singleton unreviewed botanical size reports from Stage103/104 are NOT silently merged into the A-grade measured-source flower diameter median.

Report for each outcome and wind threshold: original regions n, geographic source blocks n, raw source-region rank Spearman rho, rank-partial after NHM/WFO source documentation coverage, further rank-partial after latitude, matching-era local model 2m temperature and separately labelled 1970–2000 WorldClim precipitation, then rank-partial with 17 geographic source block fixed effects. Report leave-one-source-block-out min/max raw rho as an observational leverage diagnostic, **not** spatial confidence interval, and NO naive independent-and-identically-distributed source region p-values. Block fixed effects with many singleton regions may be non-identifiable for small trait cohorts: NULL means insufficient rank contrast, not zero biological effect.

Source reporting is potentially driven by the same biogeography and taxonomy as actual plant morphology. Simple partial correlation does not identify a controlled causal effect: the source observation process, overlapping repeated species among TDWG regions, geography, phylogeny and true pollinator availability remain incompletely measured. A positive sign after adjustment is not proof of wind adaptation; attenuation after reporting adjustment is evidence of instability, not a biological null.
