# Independent decision-layer screen v1

Status: post-freeze empirical bridge screen. This document does **not** modify the frozen Evolution Letters V5 submission surface.

## Question

The Villavicencio annual Stage-1 analysis now establishes that repeated plant-pollinator link dynamics are estimable and that independently measured conventional filters predict held-out link gains and losses.

The remaining formal gap is different:

> Can a decision-relevant exposure be measured independently of the network response, rather than inferred from the same links it is asked to explain?

The screen below separates three evidential roles:

1. repeated network response;
2. independent cognition / decision measurement;
3. experimental manipulation of environmental decision complexity.

No single public dataset is currently assumed to provide all three.

## Admission classes

- **A-exact:** repeated ecological network plus an independently measured cue hierarchy sufficient to define the focal contingent decision problem.
- **A-cognition:** ecological network plus direct independent behavioral discrimination or learning data, but without a complete cue hierarchy.
- **B-experiment:** controlled decision experiment that manipulates environmental choice structure or signal complexity but lacks a natural repeated network response.
- **C-proxy:** traits or perceptual distances only; useful conventional or restricted-channel proxies, not a direct decision layer.

## Candidate 1 — Kent Island pollinator cognition network

**Jones et al. 2025, Biology Letters, DOI 10.1098/rsbl.2025.0044.**  
Data DOI: **10.5061/dryad.9p8cz8wtm**.

The public dataset contains:

- a Kent Island plant-pollinator network for 2019, 2022 and 2023;
- plant phenology;
- floral reflectance spectra;
- bee-colour-space summaries;
- an independent colour-learning experiment;
- six tested Hymenoptera species: *Bombus flavidus*, *B. sandersoni*, *B. ternarius*, *Dolichovespula arenaria*, *D. norvegicoides* and *Megachile melanophaea*.

The learning assay was performed independently of the field interaction response. Insects were trained to associate blue or yellow with sucrose and then received repeated two-choice trials.

### Admission

**A-cognition — strongest current independent decision-layer candidate.**

This dataset closes a major gap left by Villavicencio: it measures a real decision process directly rather than replacing cognition with morphology.

It is **not A-exact** because the assay measures one colour-learning discrimination task, not the full ecological cue hierarchy required to define exact decision-equivalence classes for field partner choice.

### Allowed bridge

The dataset can support a restricted claim:

> independently measured colour-learning performance can be tested as an information-processing layer between floral opportunity / colour structure and realized plant use.

It cannot by itself establish environmental routeability in the full V5 sense.

### Important novelty boundary

The original paper already reports that species with higher network specialization made a larger proportion of correct choices in the colour-learning task, and that more generalist species visited flowers that were more similar in hymenopteran colour space.

Therefore a reanalysis that merely regresses specialization on learning score is **not novel**.

A useful routeability follow-up must instead ask a different frozen question, for example whether an independently defined perceptual partition of the available flower set changes the relationship between raw plant richness and interaction-relevant colour complexity.

Any such analysis must be labelled **restricted colour-channel structure**, not exact decision equivalence.

## Candidate 2 — Choice in a floral marketplace

**Austin, Horack & Dunlap 2018, Behavioral Ecology, DOI 10.1093/beheco/ary190.**  
Data DOI: **10.5061/dryad.0rh6sg5**.

The experiment manipulated three properties of artificial-flower environments in a full factorial design:

- number of flower choices;
- reward reliability;
- floral signal complexity.

Measured responses include:

- decision latency;
- preference / selectivity;
- constancy;
- foraging efficiency.

### Admission

**B-experiment — strongest current direct decision-cost calibration candidate.**

The experiment is highly relevant because it separates the number of alternatives from other properties of the choice environment and measures decision latency directly.

However, it does not provide the hierarchical branching structure that defines routeability in V5, and it is not a repeated natural interaction network.

### Allowed bridge

Use it as external behavioral calibration for the broad proposition that raw choice richness and decision cost need not be interchangeable.

Do not claim it directly tests the V5 routeability theorem.

## Candidate 3 — Economic foraging / decoy effects in bumblebees

Dryad DOI: **10.5061/dryad.08kprr5bb**.

The public data contain visit-by-visit choices by *Bombus impatiens*, flower colour, reward concentration, reward rate, flower state and accept/reject behavior under binary and trinary choice sets.

### Admission

**B-experiment / context-dependence control.**

This dataset is useful because adding a third alternative can alter preference between existing alternatives. It demonstrates context-dependent choice structure, but it is not a natural network and does not define the routeability hierarchy.

## Triangulation design

The current strongest empirical program is therefore not to force one dataset to do everything.

### System N — repeated network response

**Villavicencio.**

Role:

- repeated link gain / loss;
- phenology, abundance and morphology;
- temporal holdout;
- conventional-filter residual target.

Current status: **green Stage-1 response and conventional baseline**.

### System C — independent cognition plus network

**Kent Island.**

Role:

- direct learning assay;
- plant-pollinator network;
- flower colour structure;
- phenology;
- independent cognition-to-network bridge.

Current status: **A-cognition candidate; requires a new question that does not duplicate Jones et al. 2025.**

### System X — controlled decision-cost experiment

**Austin et al. floral marketplace.**

Role:

- direct manipulation of environmental choice properties;
- decision latency and behavioral selectivity;
- behavioral calibration of heterogeneity-versus-decision-cost separation.

Current status: **B-experiment calibration; not a network confirmation.**

## Preferred next empirical sequence

1. Finish the Villavicencio conventional-filter block ablation.
2. Freeze a Kent Island **restricted colour-channel** analysis that uses only externally measured reflectance / perceptual structure and independent learning performance.
3. Require the Kent analysis to preserve the original-paper novelty boundary: no replication of specialization-versus-learning as the headline.
4. Use the Austin experiment only as an external behavioral calibration unless a genuinely routeability-specific contrast can be defined before outcome inspection.
5. Keep the exact V5 claim separate from all restricted-channel empirical bridges.

## Candidate Kent question

A defensible prospective question is:

> For the six experimentally tested pollinator species, does the gap between raw floral richness and independently defined colour-space complexity predict field plant use differently for stronger versus weaker colour learners?

This is closer to the V5 ecological idea because it separates raw plant richness from a task-relevant perceptual representation.

It still remains one-channel and organism-specific.

### Exposure construction rule

Before inspecting the focal network contrast:

- calculate plant colour positions from the published reflectance data using the same hymenopteran visual model used by the source study;
- freeze a perceptual grouping / distance rule from external visual-ecology literature or from the source study's prespecified colour-space representation;
- derive raw plant richness and restricted colour-channel complexity from plant availability, not from observed interaction links;
- summarize independent colour-learning performance from the laboratory assay without using field-network outcomes.

### Forbidden shortcuts

- do not choose colour thresholds to maximize network prediction;
- do not use network specialization to define the decision exposure;
- do not call perceptual colour classes exact decision-equivalence classes;
- do not claim that colour learning alone determines realized interactions;
- do not combine Kent and Villavicencio into one effect estimate merely because both are plant-pollinator systems.

## Current conclusion

The empirical program is no longer blocked by the absence of any independent decision data.

**Kent Island supplies a real independent cognition layer.**

What remains missing is an exact natural-history dataset in which the full contingent cue hierarchy itself is measured independently of the network response. Until such a dataset is found or experimentally created, V5's empirical extensions should be described as restricted-channel or cognition-layer tests rather than exact routeability confirmation.
