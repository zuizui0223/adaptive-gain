# Figure legends — relational routeability v3

## Figure 1. Entropic equivalence does not imply adaptive equivalence

**A**, One physical 12-state, four-cue environment with two alternative focal
target/action maps. Every binary cue is exactly 6:6 balanced and the cue matrix
is identical between the two tasks. **B**, The two tasks have the same complete
Shannon entropy vector: \(H_A(U)=H_B(U)\) for every subset of the target and
four cues. Consequently their fixed exact-resolution costs are identical,
\(C_F=4\), because fixed resolution is characterized by
\(H(T\mid Q_S)=0\). **C**, Optimal adaptive resolution differs despite this
static entropic equivalence: \(C_A=4\) for Twin A and \(C_A=3\) for Twin B.
The difference arises because realized cue outcomes leave different
continuation problems. **D**, Under \(r\)-fold Cartesian products, complete
Shannon entropic equivalence is preserved while
\((C_A,C_F)=(4r,4r)\) for Twin A and \((3r,4r)\) for Twin B, so the
adaptive-cost difference grows as \(r\). This additive amplification does not
establish an unbounded separation for a fixed binary action alphabet.

## Figure 2. Finite budgets and temporal predictability expose decision structure

**A**, Routeability changes guaranteed feasibility only in the intermediate
budget window \(C_A\le B<C_F\); below \(C_A\) neither access mode is
sufficient, whereas above \(C_F\) both are sufficient. **B1**, In the minimal
temporal routing model, every fixed two-query bundle has accuracy \(3/4\),
whereas the optimal contingent policy gains
\(G_{\rm time}=|2\rho-1|/4\). Routing value is zero at temporal independence
\((\rho=1/2)\) and rises symmetrically toward predictable alternation and
predictable persistence. **B2**, One peer-reviewed quantitative biological
example: in Spaethe et al. (2026), the secondary-cue recruitment index rises
from \(R=0.026\) when the primary colour cue is easy to \(R=0.374\) when it
is difficult (pooled Cliff's \(\delta=0.980\)). **B3**, Parasitoid host
finding, multi-stage predator assessment in fiddler crabs and repeated
patch-foraging stay/leave decisions illustrate staged information use outside
pollination. These examples establish biological scope, not direct estimates of
\(C_A\) or \(C_F\). **C**, The prospective causal test holds one physical cue
matrix fixed, changes only the action-conditioned branch structure, manipulates
costly cue access under a shared budget, and predicts a positive
architecture-by-access effect only inside the routeability-sensitive window.
**D**, Empirical measurement begins with a focal action, represented
alternatives, cue outcomes and cue costs; \(C_A\) and \(C_F\) are computed
from that action-conditioned table before comparison with the biological
budget.
