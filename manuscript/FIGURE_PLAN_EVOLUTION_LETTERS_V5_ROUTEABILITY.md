# Evolution Letters figure plan V5 — environmental routeability

Status: environment-centered candidate. The machine-frozen V4 figures remain preserved.

## Design principle

Each main figure must answer an ecological question about environments or communities.

The three figures should read as:

1. **Can equally diverse environments differ in effective complexity?**
2. **Can biodiversity increase without increasing decision complexity?**
3. **Can information structure filter realized community interactions and temporal effects?**

Individual sensing architecture appears only as the mechanism connecting environmental structure to these ecological outcomes.

---

## Figure 1. Same ecological diversity, different routeability

### Panel A — equal richness

Show two communities with the same number of resource types, for example eight resources.

**Routeable community**
- an early cue partitions resources into two broad groups;
- a second cue partitions only the realized group;
- terminal information is branch-specific.

**Non-routeable community**
- the same eight resources are present;
- resource-specific terminal cues remain jointly relevant.

Labels should state:
- same resource richness;
- same number of represented alternatives;
- different information architecture.

### Panel B — effective complexity

Represent the task-specific pair \((C_A,C_F)\).

For the routeable community:
- \(C_A\) remains shallow;
- \(C_F\) is much larger.

For the non-routeable community:
- contingent and fixed costs are closer.

Do not present \(g=C_F-C_A\) as a universal complexity score.

### Panel C — ecological conclusion

Large central statement:

> **Diversity is not complexity.**

Supporting line:

> Effective complexity depends on whether heterogeneity can be partitioned into conditionally relevant branches.

## Figure 2. Richness and interaction-relevant richness can diverge

### Panel A — adding states within an equivalence class

Start with three ecological alternatives that map to one focal action/continuation structure.

Add several taxonomically distinct states inside the same decision-equivalence class.

Show:
- raw richness increases;
- contingent resolution cost remains unchanged.

### Panel B — adding a new decision branch

Add one alternative that requires a new branch-specific distinction.

Show:
- raw richness increases by only one;
- decision-relevant complexity increases.

### Panel C — niche breadth implication

Contrast:

**Routeable resource environment**
- many resources;
- few decision classes per encounter;
- broad niche remains information-feasible.

**Non-routeable resource environment**
- similar resource richness;
- many independent terminal distinctions;
- stronger information burden.

Claim ceiling:

> Routeability modifies the information cost of broad niche use; it does not determine niche breadth by itself.

## Figure 3. Routeability filters compatibility-permitted ecological interactions

### Panel A — same compatibility-permitted network

Show one consumer connected to multiple resources after morphology, phenology and encounter constraints have already been satisfied.

Use the same compatibility-permitted network for both comparison systems.

### Panel B — different behaviorally accessible networks

**Routeable environment**
- more compatibility-permitted links fit within the ecological budget;
- larger behaviorally accessible subnetwork.

**Non-routeable environment**
- fewer compatibility-permitted links can be reliably resolved within the same budget;
- smaller accessible subnetwork.

Do not equate behaviorally accessible with realized. Morphology and phenology are treated upstream as compatibility filters; competition, demography and local abundance can still remove links downstream.

### Panel C — temporal filter

Show two environmental sequences with the same persistence.

**Decision-relevant recurrence**
- recurrent states switch among different routeability/payoff classes;
- long-run evolutionary effect is amplified.

**Decision-equivalent recurrence**
- recurrent states differ physically but not in focal decision structure;
- persistence has little effect through this mechanism.

Main statement:

> Environmental persistence matters when persistent states differ in interaction-relevant structure.

## Figure-level claim firewall

- Routeability is task-specific and relational, not a universal scalar property of a community.
- Same richness does not imply same effective complexity.
- Decision-equivalence is defined only for the declared focal action.
- Routeability can modify the information cost of broad niche use; it does not imply routeability alone causes generalism.
- Behaviorally accessible interactions are a subset of potential interactions, but are not automatically realized.
- Environmental persistence matters through alignment with decision-relevant structure, not autocorrelation alone.
- No main figure should display Bellman recursions, exact Pareto corners, certificate machinery or proof-internal notation.
