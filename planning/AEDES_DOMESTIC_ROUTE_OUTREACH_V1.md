佐久間 千紗子 先生

突然のご連絡失礼いたします。

Aedes aegypti における吸血前の host-seeking 状態と成熟 gravid 状態の間で、利用する感覚情報がどのように切り替わるかを、事前に固定した有限タスクとして検証する研究計画を進めております。

先生のチームが Aedes aegypti をモデルとして、吸血・卵成熟・生殖周期に伴う代謝・行動状態の転換を研究されていることを拝見し、国内で本計画との科学的適合性が最も高い研究環境の一つではないかと考え、ご相談させていただきました。

現在の計画では、

- host側：acidic host cue / IR8a 系
- gravid側：humidity / Ir68a Moist Cell 系
- state側：NPYLR7/NPF/RYamide を含む内的状態操作

を段階的に検証し、まず安価な薬理・行動screenで state-dependent な A/B dependency shift が存在するかを判定した後に、必要な場合のみ遺伝学的統合へ進む設計にしています。

まだ共同研究を前提とした依頼ではなく、まず以下の点について feasibility を伺えればと考えております。

1. 現在の施設で外部由来 Aedes aegypti 系統（卵）の受入・飼育が可能か
2. host-seeking assay と gravid oviposition/humidity-seeking assay を同一施設内で実施する現実性
3. 現在維持されている Liverpool-derived 系統の pedigree（LVP-IB12 か、別 Liverpool 系統か）
4. このような state-dependent sensory routing の共同検証にご関心をお持ちいただける可能性があるか

遺伝背景を後から都合よく置き換えないことを重視しており、現在維持されている Liverpool 系統を LVP-IB12 と仮定することはしておりません。

お忙しいところ恐縮ですが、もし研究上の接点がありそうでしたら、一度ご相談の機会をいただけますと幸いです。
