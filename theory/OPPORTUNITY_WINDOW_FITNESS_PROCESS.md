# Opportunity-window fitness process

Status: side theory on branch theory/opportunity-fitness-process-v1. This note is not yet part of the frozen manuscript. It replaces the strongest part of the ad hoc gap-to-fitness lift with an explicit natural-history process.

## 1. Biological question

The exact finite decision theory gives

\[
C_A\le C_F,
\]

where C_A is the minimum worst-path cost of contingent target resolution and C_F is the minimum cost of a precommitted resolving bundle.

The structural gap

\[
g=C_F-C_A
\]

is not intrinsically fitness. The missing biological process is whether the ecological opportunity is still available when the decision finishes.

Let B be a nonnegative random opportunity budget on the same scale as cue-acquisition cost. Examples are time before prey escapes, time before a flower or mate is lost, tolerated exposure before predation risk becomes unacceptable, or a finite energetic/handling opportunity.

Define the survival function

\[
S_B(c)=\Pr(B\ge c).
\]

Successful resolution by cost c therefore has opportunity probability S_B(c).

## 2. Theorem OF1 — exact opportunity-window mass

Suppose correct target resolution before the opportunity closes gives benefit v>=0, and compare guarantee-level completion at costs C_A<=C_F.

The expected performance benefit uniquely available to contingent resolution is

\[
\boxed{
R_{\rm opp}
=
v[S_B(C_A)-S_B(C_F)]
=
v\Pr(C_A\le B<C_F).
}
\]

Proof. The contingent guarantee succeeds when B>=C_A; the fixed guarantee succeeds when B>=C_F. Since C_A<=C_F, the set difference is exactly {C_A<=B<C_F}. Multiplying its probability by v gives the result.

This removes the hard-budget discontinuity without removing the original adaptive-only window. The hard-budget model is recovered by a degenerate distribution concentrated at one value B=b.

If maintaining contingent control has additive expected-fitness debit K>=0, define

\[
\boxed{
\Phi_{\rm opp}=R_{\rm opp}-K.
}
\]

Contingent control is favored in this minimal process exactly when Phi_opp>0.

This is a direct bridge to architecture-value logic: the recoverable benefit is now generated by natural-history timing rather than posited as a linear multiple of g.

## 3. Corollary — the structural gap alone is not fitness-sufficient

Two tasks can have the same

\[
g=C_F-C_A
\]

but different opportunity-window mass because

\[
\Pr(C_A\le B<C_F)
\]

depends on the location of the interval, not only its width.

Therefore

\[
\boxed{
C_F-C_A
\text{ alone does not identify the fitness value of routeability.}
}
\]

The pair (C_A,C_F), together with the opportunity distribution, is biologically relevant.

If B has density f_B, then

\[
R_{\rm opp}
=
v\int_{C_A}^{C_F} f_B(b)\,db.
\]

For a small strict gap g,

\[
R_{\rm opp}
=
v f_B(C_A)g+o(g).
\]

Thus a local linear lift exists, but its coefficient is natural-history dependent:

\[
\lambda_{\rm local}=v f_B(C_A),
\]

not a universal constant.


## 3b. Theorem OF1.1 — exact stochastic-opportunity selection coefficient

The opportunity-window mass is an expected performance difference. To connect it directly to allele- or architecture-frequency change, let baseline fitness be w0>0 and let timely correct resolution add value v>=0.

Define

\[
W_A
=
e^{-\kappa}[w_0+vS_B(C_A)]
\]

for the contingent architecture and

\[
W_F
=
w_0+vS_B(C_F)
\]

for the fixed architecture, where kappa>=0 is the log maintenance cost of contingent control.

The exact log-fitness selection coefficient is

\[
\boxed{
s_{\rm opp}
=
\log\frac{W_A}{W_F}
=
\log
\frac{w_0+vS_B(C_A)}
{w_0+vS_B(C_F)}
-\kappa.
}
\]

Therefore contingent control is favored exactly when

\[
\boxed{
\kappa
<
\log
\frac{w_0+vS_B(C_A)}
{w_0+vS_B(C_F)}.
}
\]

For a deterministic hard budget B=b, use

\[
S_B(c)=\mathbf 1\{b\ge c\}.
\]

The formula then recovers the repository's existing three-region result exactly:

\[
b<C_A
\quad\Rightarrow\quad
s_{\rm opp}=-\kappa,
\]

\[
C_A\le b<C_F
\quad\Rightarrow\quad
s_{\rm opp}
=
\log\frac{w_0+v}{w_0}-\kappa,
\]

and

\[
b\ge C_F
\quad\Rightarrow\quad
s_{\rm opp}=-\kappa.
\]

Thus the hard-budget model is not a separate fitness construction. It is the degenerate-opportunity special case of the stochastic process.

For weak performance value relative to baseline, r=v/w0 -> 0,

\[
s_{\rm opp}
=
r[S_B(C_A)-S_B(C_F)]
-\kappa
+O(r^2).
\]

If the strict structural gap g=C_F-C_A is also small and B has density f_B, then

\[
S_B(C_A)-S_B(C_F)
=
f_B(C_A)g+o(g),
\]

so

\[
\boxed{
s_{\rm opp}
=
\frac{v}{w_0}f_B(C_A)g-\kappa
+o(g)+O((v/w_0)^2).
}
\]

This gives a biological interpretation to the old linear coefficient:

\[
\boxed{
\lambda_{\rm local}
=
\frac{v}{w_0}f_B(C_A).
}
\]

It combines the value of timely resolution with the density of ecological opportunity limits exactly where contingent routing saves time. It is therefore system- and context-dependent rather than a universal conversion from structural gap to fitness.

Under haploid viability selection the frequency process is then

\[
\operatorname{logit}(p_{t+1})
=
\operatorname{logit}(p_t)+s_{\rm opp},
\]

so the natural-history timing layer plugs directly into the repository's existing evolutionary-response machinery without positing s=lambda g-kappa as a primitive assumption.


## 4. Theorem OF2 — exponential opportunity closure gives a unique intermediate optimum

Assume opportunities close at constant hazard mu>0:

\[
B\sim\operatorname{Exp}(\mu),
\qquad
S_B(c)=e^{-\mu c}.
\]

For

\[
0<C_A<C_F,
\]

the routeability-generated opportunity benefit is

\[
\boxed{
R_{\rm opp}(\mu)
=
v(e^{-\mu C_A}-e^{-\mu C_F}).
}
\]

It tends to zero as mu approaches either zero or infinity. It has one unique maximum at

\[
\boxed{
\mu^*
=
\frac{\log(C_F/C_A)}{C_F-C_A}.
}
\]

Proof. Differentiate:

\[
\frac{1}{v}\frac{dR_{\rm opp}}{d\mu}
=
-C_Ae^{-\mu C_A}
+
C_Fe^{-\mu C_F}.
\]

The stationary condition is

\[
e^{-\mu(C_F-C_A)}=C_A/C_F,
\]

which gives the stated mu*. The derivative is positive below this point and negative above it.

The maximum window mass is

\[
\boxed{
\frac{R_{\rm opp}(\mu^*)}{v}
=
\frac{C_F-C_A}{C_F}
\left(\frac{C_A}{C_F}\right)^{C_A/(C_F-C_A)}.
}
\]

Hence selection for contingent sensing is band-pass with respect to ecological closure pressure in this minimal model:

- very low hazard: both architectures usually finish;
- intermediate hazard: the saved decision time changes success probability;
- very high hazard: even the contingent architecture rarely finishes.

A constitutive cost K shifts this curve downward. Positive selection exists only if K is below the maximum opportunity benefit.


### Corollary OF2.1 — maintenance cost creates two ecological selection boundaries

Let the contingent architecture pay a constitutive expected-fitness cost K with

\[
0<K<R_{\rm opp}(\mu^*).
\]

Because R_opp(mu) is continuous, tends to zero at both ecological extremes, and has one strict interior maximum, the equation

\[
R_{\rm opp}(\mu)=K
\]

has exactly two positive solutions

\[
\mu_-<\mu^*<\mu_+.
\]

Therefore

\[
\boxed{
\Phi_{\rm opp}(\mu)>0
\iff
\mu_-<\mu<\mu_+.
}
\]

So increasing ecological closure pressure can reverse selection twice without changing cue topology:

fixed favored -> contingent favored -> fixed favored.

The first reversal occurs when opportunities become tight enough that routeability begins to rescue otherwise-lost decisions. The second occurs when opportunities become so short that even the contingent architecture usually fails, leaving only its constitutive cost.


## 5. Theorem OF3 — equal structural gaps can have ordered fitness values

Write

\[
g=C_F-C_A>0.
\]

Under exponential closure,

\[
R_{\rm opp}
=
v e^{-\mu C_A}(1-e^{-\mu g}).
\]

For fixed g, v, and mu>0, this is strictly decreasing in C_A.

Therefore two decision systems with the same structural adaptive gain can experience systematically different selection:

\[
\boxed{
g_1=g_2
\not\Rightarrow
R_{{\rm opp},1}=R_{{\rm opp},2}.
}
\]

Saving one unit from a short decision can matter far more than saving one unit from a decision that is already usually too late.

This is the simplest mechanistic reason not to use

\[
s=\lambda g-\kappa
\]

as a universal fitness map.

## 6. Theorem OF4 — pathwise process and a guarantee-level lower bound

The worst-path quantities are sufficient for guaranteed resolution, but realized fitness can depend on branch-specific completion times.

Let ecological state x occur with probability p_x. Let an exact contingent policy finish in cost T_A(x), with

\[
T_A(x)\le C_A
\]

for every represented state. Let the chosen minimum fixed bundle cost C_F; because the full precommitted bundle is acquired, its cost is state-independent.

If every correctly resolved state has the same benefit v and the opportunity survival function S_B is common across states, then the realized expected performance advantage is

\[
R_{\rm path}
=
v\sum_x p_x
[S_B(T_A(x))-S_B(C_F)].
\]

Because S_B is nonincreasing and T_A(x)<=C_A,

\[
\boxed{
R_{\rm path}
\ge
v[S_B(C_A)-S_B(C_F)]
=
R_{\rm opp}.
}
\]

Thus the opportunity-window result derived only from (C_A,C_F) is a conservative lower bound on the performance benefit of a chosen worst-case-optimal contingent tree under the stated common-value/common-survival assumptions.

If state values, hazard distributions, errors, or path costs differ, the full pathwise expression is the relevant biological object:

\[
W(\pi)
=
\sum_x p_x v_x S_x(T_\pi(x))-K_\pi.
\]

This makes explicit what additional natural-history measurements are required beyond the finite guarantee theory.


## 6b. Theorem OF5 — even (C_A,C_F) does not identify realized expected fitness

The guarantee pair is enough for the lower bound in OF4, but it does not determine the exact pathwise opportunity benefit.

There exist two unit-cost finite deterministic tasks with all of the following held fixed:

- five represented worlds;
- three declared queries;
- target counts 3 versus 2;
- C_A=2;
- C_F=3;
- the same two terminal-query outcome vectors.

They differ only in the routing outcome of one target-0 world.

In Task A that world joins an already mixed routing branch. The selected optimal contingent tree therefore uses two acquisitions on every represented world:

\[
T_A(x)=2\quad\forall x.
\]

In Task B the same world receives its own root outcome, which is already target-pure. The selected optimal contingent tree therefore has path-cost multiset

\[
\{1,2,2,2,2\}.
\]

Under a uniform world distribution and any strictly decreasing opportunity survival function S_B,

\[
R_{\rm path}^{(A)}
=
v[S_B(2)-S_B(3)],
\]

whereas

\[
R_{\rm path}^{(B)}
=
v\left[
\frac15S_B(1)+\frac45S_B(2)-S_B(3)
\right].
\]

Hence

\[
\boxed{
R_{\rm path}^{(B)}-R_{\rm path}^{(A)}
=
\frac{v}{5}[S_B(1)-S_B(2)]
>0.
}
\]

Therefore

\[
\boxed{
(C_A,C_F)
\text{ does not identify realized expected fitness.}
}
\]

The hierarchy is now:

\[
g=C_F-C_A
\]

is insufficient even for the guarantee-level opportunity value;

\[
(C_A,C_F)
\]

determines an exact guarantee-level lower bound but not exact realized expected fitness;

the branchwise distribution of completion costs, together with state probabilities, state values, and opportunity survival, determines the pathwise process.

This is not a defect of the worst-case theory. It clarifies its biological role: worst-case routeability provides a guaranteed performance floor, while evolutionary fitness generally depends on how often each branch is encountered and how quickly that branch terminates.



## 6c. Theorem OF6 — stochastic completion times reduce fitness to distribution overlap

Real organisms need not complete the same decision in a deterministic time on every encounter.

For architecture j, let

\[
T_j\in[0,\infty]
\]

be the random time or acquisition cost at which the correct focal action is resolved. Trials that never resolve correctly may be represented by T_j=infinity.

Let B be the random ecological opportunity limit.

The timely-success probability is always

\[
q_j=\Pr(T_j\le B).
\]

If B is independent of T_j conditional on the declared ecological state, with opportunity CDF G and completion-time CDF F_j, then

\[
\boxed{
q_j
=
E_B[F_j(B)]
=
E_{T_j}[S_B(T_j)].
}
\]

Therefore the performance advantage of architecture i over architecture j is

\[
\boxed{
R_{i:j}
=
vE_B[F_i(B)-F_j(B)].
}
\]

This is the distributional version of the opportunity-window theorem.

For deterministic completion times

\[
T_A=C_A,
\qquad
T_F=C_F,
\]

the CDF difference is one exactly on

\[
[C_A,C_F)
\]

and zero elsewhere, recovering

\[
R_{A:F}=v\Pr(C_A\le B<C_F).
\]

### Consequence — deadline experiments can estimate the relevant performance object directly

At an experimentally imposed deadline b,

\[
F_j(b)=\Pr(T_j\le b)
\]

is simply the probability of a correct completed decision by that deadline.

Thus an experiment that randomizes presentation durations or opportunity windows can estimate the entire curve

\[
b\mapsto F_j(b)
\]

without first forcing every trial into one deterministic cost.

Natural-history measurements of the opportunity distribution G then supply the ecological weighting:

\[
\boxed{
R_{i:j}
=
v\int [F_i(b)-F_j(b)]\,dG(b).
}
\]

The fitness-relevant object is therefore the **overlap between the architecture performance-difference curve and the distribution of ecological opportunity limits**.

### Consequence — mean decision time is not sufficient

Two architectures can have the same mean completion time but different early tails, and therefore different values under short ecological opportunities.

Likewise, one architecture can have a lower mean completion time but little fitness advantage if its improvement occurs mostly at durations where ecological opportunities rarely terminate.

Hence neither worst-case cost, structural gap, nor mean latency alone identifies selection.


### Corollary OF6.1 — equal mean latency can still reverse selection

Consider two completion-time distributions with equal mean:

\[
T_X=
\begin{cases}
1,&1/2\\
3,&1/2
\end{cases}
\]

and

\[
T_Y=2
\]

deterministically. Both have mean 2.

If the ecological opportunity is deterministically

\[
B=1.5,
\]

then

\[
\Pr(T_X\le B)=1/2,
\qquad
\Pr(T_Y\le B)=0,
\]

so X has the higher timely-success probability.

If instead

\[
B=2.5,
\]

then

\[
\Pr(T_X\le B)=1/2,
\qquad
\Pr(T_Y\le B)=1,
\]

so Y has the higher timely-success probability.

Thus

\[
\boxed{
E[T_X]=E[T_Y]
\quad\text{while the sign of selection reverses with the opportunity distribution.}
}
\]

Mean decision speed is therefore not an evolutionarily sufficient summary even when the two architectures have identical average latency.


### Exact log-fitness comparison

With baseline fitness w0>0, timely-resolution value v>=0, and architecture log costs kappa_i and kappa_j,

\[
\boxed{
s_{i:j}
=
\log
\frac{w_0+vq_i}
{w_0+vq_j}
-
(\kappa_i-\kappa_j),
}
\]

where

\[
q_i=\Pr(T_i\le B),
\qquad
q_j=\Pr(T_j\le B).
\]

This formula is directly estimable from individual-level time-to-decision data and opportunity-duration data.

### Dependence caveat

If the ecological opportunity limit responds to the organism's behavior—for example, a host becomes defensive after probing—B and T need not be independent.

Then the primitive quantity remains

\[
q_j=\Pr(T_j\le B_j)
\]

under the joint process for architecture j.

The overlap integral using separate marginal distributions is licensed only when conditional independence, external deadline randomization, or another justified decomposition applies.


## 7. Process interpretation

The causal chain is:

ecological alternatives + cue topology
-> contingent versus fixed completion costs
-> opportunity-window overlap
-> probability of completing the correct action in time
-> ecological payoff
-> fitness margin after architecture cost
-> selection

The central biological object is not routeability by itself. It is the overlap between where routeability saves decision cost and where ecological opportunities actually close.

The sharper prediction is:

Contingent sensing should be most strongly favored when the distribution of opportunity limits places substantial probability mass between the contingent and fixed completion costs.

## 8. Relation to PAYOFF

PAYOFF uses an architecture margin of the form

\[
\Phi=R-K.
\]

The present process supplies a mechanistic candidate for R:

\[
\boxed{
R
=
v\Pr(C_A\le B<C_F)
}
\]

at the guarantee level, or the pathwise expected-payoff difference when branch-specific costs and values are observed.

Thus the repositories answer different parts of one chain:

adaptive-gain:
decision topology -> opportunity-dependent recoverable benefit R

PAYOFF:
recoverable benefit R - architecture cost K -> architecture value Phi

No claim is made that all PAYOFF architecture benefits arise from information acquisition.

## 9. Prior-art boundary

Time costs, speed-accuracy tradeoffs, sequential sampling, stochastic hazards, and fitness consequences of delayed decisions are established topics. Relevant background includes Chittka et al. (2009, Trends in Ecology & Evolution), de Froment et al. (2014, PLOS Computational Biology), and Houston (2014, Journal of Animal Ecology).

The narrow repository-specific result is the composition of that natural-history timing logic with the exact adaptive/fixed guarantee pair (C_A,C_F):

\[
(C_A,C_F)
\to
\Pr(C_A\le B<C_F)
\to
R_{\rm opp}
\to
R_{\rm opp}-K.
\]

Novelty should not be claimed for exponential survival or differentiation of the resulting curve by itself.

## 10. Scope

This note still assumes exact eventual target resolution and does not yet include noisy cue observations, accuracy below full target resolution, learning costs, endogenous stopping thresholds, state-dependent opportunity values in the guarantee-level theorem, or demographic feedback after the immediate fitness map. Those belong in later process layers rather than being hidden inside C_A or C_F.
