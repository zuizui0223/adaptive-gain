# Identifiability of evolutionary persistence, community memory, and structural loop gain

## Status and relation to the earlier inverse branch

The inverse-feedback branch derived an exact local inverse for the parent
haploid-logit feedback model.  In that model the evolutionary coordinate has
intrinsic persistence fixed at

\[
\alpha=1,
\]

so a phenotype time series identifies community memory and loop gain.

The generalized evolutionary-response branch removes that fixed-response
assumption.  Once

\[
\alpha
\]

is itself unknown, the earlier two-parameter inverse becomes a three-parameter
identifiability problem.

This note states the resulting boundary exactly.

No novelty is claimed for trace/determinant identifiability of a linear
second-order system.  The repository-specific consequence is that the exact
finite sensing gap cannot generally be inferred from transient geometry unless
one ecological or evolutionary memory component is constrained independently.

---

## 1. Generalized local dynamics

The generalized branch has local Jacobian

\[
J=
\begin{pmatrix}
\alpha & \beta\Delta s\\
(1-\phi)e & \phi
\end{pmatrix},
\]

where

- \(\alpha\in[0,1]\) is intrinsic evolutionary persistence;
- \(\beta\) is local responsiveness to selection;
- \(\phi\in[0,1)\) is community memory;
- \(e\) is the local effect of evolutionary state on target community state;
- \(\Delta s\) is state-specific selection contrast.

Define generalized loop gain

\[
\boxed{
G=-\beta\Delta s\,e.
}
\]

Then the two local characteristic invariants are

\[
\boxed{
T=\operatorname{tr}J=\alpha+\phi,
}
\]

and

\[
\boxed{
D=\det J
=\alpha\phi+(1-\phi)G.
}
\]

Every coordinate of the local two-dimensional system satisfies the
characteristic recurrence

\[
\boxed{
x_{t+2}=T x_{t+1}-D x_t}
\]

provided the observed coordinate contains the relevant local modes.

Therefore an ideal local scalar time series identifies at most

\[
(T,D).
\]

---

## 2. The exact equivalence ridge

There are three biological quantities

\[
(\alpha,\phi,G)
\]

but only two observed invariants

\[
(T,D).
\]

For any candidate community memory \(\phi\), trace fixes

\[
\boxed{
\alpha(\phi)=T-\phi.
}
\]

Substituting into the determinant gives

\[
\boxed{
G(\phi)
=
\frac{D-\phi(T-\phi)}{1-\phi}
=
\frac{D-T\phi+\phi^2}{1-\phi}.
}
\]

Thus the observational equivalence class is

\[
\boxed{
\mathcal E(T,D)
=
\left\{
(T-\phi,\phi,G(\phi)):
\phi\text{ biologically feasible}
\right\}.
}
\]

The transient alone does not choose one point on this ridge.

---

## 3. Feasible memory interval

Because

\[
0\le\alpha\le1
\]

and

\[
0\le\phi<1,
\]

we require

\[
\alpha=T-\phi.
\]

Therefore a biological decomposition exists only for

\[
\boxed{0\le T<2.}
\]

The compatible memory interval is

\[
\boxed{
\max\{0,T-1\}
\le\phi\le T
}
\]

when

\[
T<1,
\]

and

\[
\boxed{
T-1\le\phi<1
}
\]

when

\[
T\ge1.
\]

So the trace alone already says how evolutionary persistence and ecological
memory can trade off.

---

## 4. The parent inverse is a collapsed special case

The parent feedback model fixes

\[
\alpha=1.
\]

Then

\[
T=1+\phi
\]

immediately yields

\[
\boxed{
\phi=T-1.
}
\]

The determinant then gives

\[
\boxed{
G
=\frac{D-\phi}{1-\phi}.
}
\]

This is exactly the earlier inverse with

\[
G=L.
\]

Therefore the statement

> phenotype transient geometry alone identifies community memory and loop gain

is correct **conditional on the parent model's \(\alpha=1\) response law**.

It is not a general property of the broader evolutionary-response model.

---

## 5. Explicit observational collision

Take the repo-native parent transient

\[
\alpha=1,
\qquad
\phi=0.8,
\qquad
G=0.125.
\]

It has

\[
T=1.8,
\qquad
D=0.825.
\]

But the same \((T,D)\) is generated by

\[
(\alpha,\phi,G)
=(0.9,0.9,0.15)
\]

and also by

\[
(\alpha,\phi,G)
=(0.81,0.99,2.31).
\]

All three systems have the same local characteristic polynomial and therefore
the same local eigenvalues, damping rate, and period.

Yet the biological interpretation of the timescale and the inferred feedback
gain are very different.

This is an exact identifiability collision, not a noisy-data phenomenon.

---

## 6. Stable high-trace transients can leave gain unbounded above

For a Schur-stable observed recurrence,

\[
1-T+D>0.
\]

Suppose

\[
T\ge1.
\]

Then feasible memory extends to

\[
\phi\to1^-.
\]

Along the equivalence ridge,

\[
G(\phi)
=
\frac{D-T\phi+\phi^2}{1-\phi}.
\]

As

\[
\phi\to1^-,
\]

the numerator tends to

\[
1-T+D>0
\]

while the denominator tends to zero from above.  Hence

\[
\boxed{
G(\phi)\to+\infty.
}
\]

Therefore:

\[
\boxed{
\text{for stable }T\ge1,
\text{ transient geometry alone gives no finite upper bound on }G.
}
\]

This has a direct structural consequence.  Even if

\[
G=(-\beta e)\lambda\Delta g
\]

under restoring feedback, the observed transient alone cannot bound
\(\Delta g\) from above unless the response decomposition is constrained.

The earlier structural inverse needs an independent response assumption or
measurement before finite-task combinatorics can be applied quantitatively.

---

## 7. When trace is below one, the ridge is compact

If

\[
T<1,
\]

then

\[
0\le\phi\le T<1.
\]

The feasible interval is compact and the gain range is finite.

The derivative is

\[
\frac{dG}{d\phi}
=
\frac{D-T+2\phi-\phi^2}{(1-\phi)^2}.
\]

An interior stationary point, when feasible, occurs at

\[
\boxed{
\phi_*
=1-\sqrt{1-T+D}.
}
\]

Thus the exact finite gain envelope is obtained by evaluating \(G\) at

- the feasible-memory endpoints; and
- \(\phi_*\), when it lies inside the interval.

This does not restore point identifiability.  It only provides a finite
identified set.

## 8. One independent memory measurement collapses the ridge

### If intrinsic evolutionary persistence is measured

Given independent

\[
\alpha,
\]

we recover

\[
\boxed{
\phi=T-\alpha
}
\]

and then

\[
\boxed{
G=
\frac{D-\alpha\phi}{1-\phi}.
}
\]

### If community memory is measured

Given independent

\[
\phi,
\]

we recover

\[
\boxed{
\alpha=T-\phi
}
\]

and the same determinant inversion yields \(G\).

Thus either independent evolutionary-memory information or independent
community-memory information is sufficient locally.

## 9. Empirical meaning of the two memory measurements

The decomposition suggests two deliberately different perturbation experiments.

### Evolutionary-response relaxation

Estimate \(\alpha\) by perturbing the evolutionary state while holding the
state-specific selection contrast near its reference value, then measuring the
one-step persistence of the evolutionary coordinate.

The exact biological realization depends on the system: allele frequency,
quantitative trait mean, behavioral architecture frequency, or another inherited
state should not be conflated without a corresponding mechanistic model.

### Community relaxation

Estimate \(\phi\) by perturbing community state while holding evolutionary state
approximately fixed, then measuring ecological relaxation toward its target.

This is a different intervention from observing the coupled system freely.

The key point is experimental orthogonalization:

\[
\boxed{
\text{free coupled trajectory identifies }(T,D),
\text{ not the source of memory.}
}
\]

## 10. Revised empirical ladder

The generalized model changes the inverse workflow.

### Package A — free evolutionary transient

Estimate

\[
T,D.
\]

This identifies the equivalence ridge only.

### Package B — one independent persistence measurement

Estimate either

\[
\alpha
\]

or

\[
\phi.
\]

Then recover the other persistence term and \(G\).

### Package C — ecological and fitness factorization

Use independent response measurements to factor

\[
G=-\beta\Delta s\,e.
\]

This stage tests whether the observed local feedback gain agrees with directly
measured selection and ecological effects.

### Package D — natural-history sensing structure

Construct the finite sensing tasks and compute

\[
\Delta g
=[(C_F-C_A)_{high}-(C_F-C_A)_{low}].
\]

Only then test the structural lift

\[
\Delta s=\lambda\Delta g
\]

or the alternative hard-budget mechanism.

This ordering prevents a long transient from being automatically attributed to
a large structural adaptive gain.

## 11. Consequence for short-term versus long-term evolution

The generalized theory now separates three sources of persistence that can look
similar in a phenotype trajectory:

\[
\boxed{
\alpha
=\text{intrinsic evolutionary persistence},
}
\]

\[
\boxed{
\phi
=\text{community persistence},
}
\]

and

\[
\boxed{
G
=\text{coupled eco-evolutionary feedback gain}.
}
\]

A long transient can therefore reflect

- a slowly relaxing evolutionary state;
- a slowly relaxing community;
- feedback close to a stability boundary;
- or a combination of all three.

The free time series identifies their combined local eigenstructure, not their
biological attribution.

This is the precise sense in which

\[
\boxed{
\text{evolutionary timescale}
\ne
\text{a single intrinsic property of evolution.}
}
\]

It is partly a property of how evolutionary memory, ecological memory, and
structural feedback are coupled.

## 12. Independent audit

The executable equivalence formulas were independently checked on 200,000
random stable generalized-response systems.

- alternative decompositions reproduced the original trace/determinant with
  maximum absolute error \(2.22\times10^{-16}\);
- among 99,791 stable draws with \(T\ge1\), the unbounded-gain criterion had zero
  failures;
- among 100,209 stable draws with \(T<1\), exact finite-envelope candidates had
  zero violations against random points on the compatible ridge.

These checks validate the algebraic identified set.  They are not statistical
identifiability results under finite samples or measurement/process noise.

---

## 13. Claim boundary

This note does not claim novelty for

- observability of trace and determinant in a second-order linear recurrence;
- parameter nonidentifiability when there are more biological factors than local
  invariants;
- experimental separation of coupled parameters in general.

The repository-specific result is the consequence for the structural sensing
programme:

```text
finite cue structure
-> structural gap Delta_g
-> selection contrast
-> generalized feedback gain G
-> local transient
```

cannot generally be reversed from the transient alone once intrinsic evolutionary
persistence is allowed to vary.

The exact adaptive-gain mathematics remains useful, but it must be combined with
an independent evolutionary- or ecological-memory measurement before the inverse
structural interpretation is identified.
