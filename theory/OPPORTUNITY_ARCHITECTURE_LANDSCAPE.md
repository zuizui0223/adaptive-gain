# Opportunity-generated architecture landscape

Status: side theory on branch theory/opportunity-fitness-process-v1.

This note asks what happens when contingent routing is not a binary architecture but can evolve through graded reductions in decision-completion time. The main result is that a simple ecological opportunity process can itself generate increasing returns and a finite-jump evolutionary barrier.

## 1. Architecture coordinate

Let

\[
r\in[0,L]
\]

denote a heritable architecture's guaranteed reduction in decision-completion cost relative to a reference architecture.

Write

\[
C(r)=C_0-r,
\qquad
0\le r\le L<C_0.
\]

Here \(r=0\) is the reference architecture and \(r=L\) is the most strongly routed architecture in the declared family.

Let baseline fitness be \(w_0>0\), and let timely correct completion add value \(v>0\).

## 2. Exponential ecological opportunity loss

Assume the ecological opportunity remains available through time \(c\) with probability

\[
S(c)=e^{-\mu c},
\qquad
\mu>0.
\]

Before architecture cost, expected fitness is

\[
W_{\rm perf}(r)
=
w_0+v e^{-\mu(C_0-r)}.
\]

Define the log-performance recovery relative to the reference:

\[
\boxed{
R(r)
=
\log
\frac{w_0+v e^{-\mu(C_0-r)}}
{w_0+v e^{-\mu C_0}}.
}
\]

This is the ecological payoff generated solely by faster completion.

## 3. Theorem OA1 — opportunity-generated recovery is strictly convex

Let

\[
A=v e^{-\mu C_0}>0.
\]

Then

\[
R(r)
=
\log(w_0+A e^{\mu r})-\log(w_0+A).
\]

Its first derivative is

\[
\boxed{
R'(r)
=
\mu
\frac{A e^{\mu r}}
{w_0+A e^{\mu r}}.
}
\]

Define

\[
p(r)
=
\frac{A e^{\mu r}}
{w_0+A e^{\mu r}}.
\]

Then

\[
R'(r)=\mu p(r)
\]

and

\[
\boxed{
R''(r)
=
\mu^2 p(r)[1-p(r)]
>0.
}
\]

Therefore the opportunity-generated log-performance recovery is strictly convex throughout the interior.

### Biological interpretation

Saving one additional unit of decision time becomes more valuable after previous routing improvements have already made timely completion reasonably likely.

When a decision is still so slow that the ecological opportunity is usually lost, a small additional speed improvement yields little payoff. Once the architecture approaches the ecologically relevant opportunity window, further improvement converts many more encounters into timely successes.

Thus the ecological process itself creates increasing returns.

## 4. Linear architecture cost gives endpoint optima

Let the constitutive log-fitness cost of routing improvement be linear:

\[
K(r)=kr,
\qquad
k\ge0.
\]

The architecture value is

\[
\Phi(r)=R(r)-kr.
\]

Because subtracting a linear function preserves strict convexity,

\[
\boxed{
\Phi''(r)>0.
}
\]

A convex function on the compact interval \([0,L]\) attains a global maximum at an endpoint.

Therefore:

\[
\boxed{
\text{under exponential opportunity loss + linear architecture cost,}
\\
\text{a globally optimal architecture is }r=0\text{ or }r=L.
}
\]

The minimal process does not generically stabilize a partially routed architecture.

This is a model-specific result, not a universal claim against graded sensory architecture.

## 5. Theorem OA2 — exact finite-jump barrier

The local selection gradient away from the reference is

\[
\Phi'(0)
=
R'(0)-k.
\]

Let

\[
p_0
=
\frac{v e^{-\mu C_0}}
{w_0+v e^{-\mu C_0}}.
\]

Then

\[
\boxed{
k_{\rm local}
=
R'(0)
=
\mu p_0.
}
\]

The full routed endpoint has greater fitness than the reference exactly when

\[
\Phi(L)>0,
\]

or

\[
k
<
\boxed{
k_{\rm global}
=
\frac{R(L)}{L}
=
\frac{1}{L}
\log\left[
1+p_0(e^{\mu L}-1)
\right].
}
\]

Strict convexity with \(R(0)=0\) implies

\[
\boxed{
k_{\rm local}<k_{\rm global}
}
\]

for every \(L>0\) and \(0<p_0<1\).

Hence there is a nonempty interval

\[
\boxed{
k_{\rm local}
<
k
<
k_{\rm global}
}
\]

in which

\[
\Phi'(0)<0
\]

but

\[
\Phi(L)>0.
\]

Therefore:

\[
\boxed{
\text{small routing improvements are selected against}
\\
\text{while a sufficiently large routing improvement has higher fitness.}
}
\]

This is an exact finite-jump barrier generated by the ecological opportunity process.

## 6. Barrier width

Define

\[
W_k
=
k_{\rm global}-k_{\rm local}.
\]

Then

\[
\boxed{
W_k
=
\frac{1}{L}
\log\left[
1+p_0(e^{\mu L}-1)
\right]
-
\mu p_0
>0.
}
\]

For small \(L\),

\[
\boxed{
W_k
=
\frac{\mu^2}{2}p_0(1-p_0)L
+O(L^2).
}
\]

The leading barrier width is therefore largest, at fixed \(\mu\) and small \(L\), near intermediate baseline timely-success contribution \(p_0=1/2\).

This gives a precise ecological interpretation: increasing returns are weakest when timely success is already nearly impossible or nearly guaranteed, and strongest near the transition between those regimes.

## 7. Relation to the binary adaptive/fixed result

Suppose the reference is a fixed architecture with completion cost

\[
C_F=C_0
\]

and the routed endpoint has

\[
C_A=C_0-L.
\]

Then

\[
L=C_F-C_A.
\]

The full endpoint performance contrast is exactly the stochastic-opportunity selection numerator already derived in the parent note.

The new result asks a different question:

> can evolution reach the routed endpoint through small architecture changes when each incremental reduction in completion time carries constitutive cost?

The answer can be no even when the endpoint is globally superior.

Thus

\[
\boxed{
\text{structural adaptive opportunity}
\neq
\text{local evolutionary accessibility}.
}
\]

## 8. Relation to PAYOFF

PAYOFF uses

\[
\Phi=R-K
\]

and contains a separate convex-recovery finite-jump modularization barrier.

The present result supplies a mechanistic ecological source for one class of convex \(R\):

\[
\boxed{
R(r)
=
\log
\frac{w_0+vS(C_0-r)}
{w_0+vS(C_0)}
}
\]

with exponential \(S\).

Thus the two repositories connect as:

\`\`\`text
adaptive-gain opportunity process
    -> convex recovery from reduced decision time
    -> local/global architecture-value mismatch

PAYOFF
    -> general R-K architecture landscape
    -> accessibility / invasion / fixation / occupancy transport
\`\`\`

The mathematical similarity should not be presented as independent novelty if the same convex-value logic is already claimed in PAYOFF. The useful result here is the ecological derivation of a PAYOFF-like barrier from explicit opportunity loss.

## 9. Beyond exponential closure

For a general differentiable survival function \(S(c)\),

\[
R(r)
=
\log[w_0+vS(C_0-r)]
-\log[w_0+vS(C_0)].
\]

The marginal value of routing is

\[
\boxed{
R'(r)
=
\frac{v f_B(C_0-r)}
{w_0+vS(C_0-r)}
}
\]

when \(f_B(c)=-S'(c)\).

Convexity is not universal. It depends on how the opportunity density changes across the completion-time range.

Therefore empirical estimation of \(S\) or \(G\) can determine whether a biological system should exhibit:

- increasing returns and a finite-jump barrier;
- approximately linear returns;
- diminishing returns and an interior optimum once architecture cost is included.

This is where natural-history time distributions become architecture-landscape data rather than descriptive timing variables.


## 9b. Theorem OA3 — ecological hazard shape determines recovery curvature

The exponential model has constant opportunity hazard and therefore convex recovery. For a general differentiable opportunity distribution, the curvature can be written directly in terms of the ecological hazard function.

Let

\[
S(c)=P(B\ge c),
\qquad
f(c)=-S'(c),
\]

and define the hazard

\[
h(c)=\frac{f(c)}{S(c)}
\]

where \(S(c)>0\).

Also define the timely-resolution contribution to total pre-cost fitness

\[
q(c)
=
\frac{vS(c)}
{w_0+vS(c)}
\in(0,1).
\]

For the architecture coordinate

\[
c=C_0-r,
\]

the marginal log-performance recovery is

\[
\boxed{
R'(r)=h(c)q(c).
}
\]

Differentiating once more gives

\[
\boxed{
R''(r)
=
q(c)
\left[
h(c)^2(1-q(c))
-
h'(c)
\right].
}
\]

### Proof

Since

\[
R(r)=\log[w_0+vS(c)]-\mathrm{constant},
\qquad
c=C_0-r,
\]

we have

\[
R'(r)
=
\frac{vf(c)}{w_0+vS(c)}
=
h(c)q(c).
\]

Further,

\[
q'(c)
=
-h(c)q(c)[1-q(c)].
\]

Therefore

\[
\frac{d}{dc}[h(c)q(c)]
=
h'(c)q(c)
-
h(c)^2q(c)[1-q(c)].
\]

Because \(dc/dr=-1\),

\[
R''(r)
=
-
\frac{d}{dc}[h(c)q(c)],
\]

which gives the stated identity. QED.

## Corollary OA3.1 — nonincreasing opportunity hazard guarantees increasing returns

If

\[
h'(c)\le0
\]

throughout the relevant completion-time interval, then

\[
R''(r)>0.
\]

Thus any constant-hazard or decreasing-hazard opportunity process generates strictly convex log-performance recovery.

The exponential model is the constant-hazard special case.

## Corollary OA3.2 — sufficiently increasing hazard can generate diminishing returns

Recovery is locally concave exactly when

\[
\boxed{
h'(c)
>
h(c)^2[1-q(c)].
}
\]

Therefore a rapidly increasing opportunity hazard can reverse the curvature created by the performance denominator and produce diminishing returns to additional routing speed.

This creates a direct ecological route to a stable partial architecture once a suitable architecture-cost function is included.

## Corollary OA3.3 — the architecture regime is empirically identifiable from time-to-opportunity data

The sign of recovery curvature is not an abstract free parameter in this process model.

Given estimates of the ecological opportunity survival curve \(S(c)\), one can estimate:

- \(h(c)\);
- \(h'(c)\);
- \(q(c)\) after calibrating \(v/w_0\);

and therefore the sign of

\[
R''(r).
\]

The theory predicts different architecture landscapes from different natural histories.

Constant or decreasing opportunity hazard produces increasing returns and a local/global accessibility gap under linear architecture cost.

Strongly increasing opportunity hazard can produce diminishing returns and make partial routing locally and globally competitive.

Hazard-shape changes across time can generate mixed curvature and multiple local architecture regimes.

This is stronger than declaring a generic convex recovery function. The curvature is generated by a measurable ecological process.

## 9c. Novelty boundary relative to PAYOFF

PAYOFF already proves the generic convex-recovery result:

\[
R''\ge0
\Longrightarrow
k_{\rm local}\le k_{\rm global},
\]

and derives an exact finite-jump modularization barrier from that geometry.

Therefore adaptive-gain should not claim the tangent-versus-secant barrier itself as an independent theorem family.

The distinct contribution here is upstream:

\[
\boxed{
\text{opportunity survival/hazard}
\to
\text{recovery curvature}
\to
\text{PAYOFF-style architecture landscape}.
}
\]

In particular, OA3 identifies when convexity should or should not arise from natural-history timing rather than assuming the shape of \(R\).


## 10. Claim boundary

Do not claim that:

- exponential opportunity loss is universal;
- sensory architectures must evolve all-or-none;
- linear architecture cost is generally realistic;
- the finite-jump idea itself is new independently of PAYOFF or established adaptive-landscape theory.

The repository-specific contribution is the explicit process derivation from:

\[
\text{decision-time reduction}
\to
\text{opportunity survival}
\to
\text{fitness recovery}
\to
\text{local/global architecture-value mismatch}.
\]
