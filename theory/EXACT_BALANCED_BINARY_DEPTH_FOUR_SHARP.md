# Sharp exact-balanced binary depth four at n=12 and n=14

Let

\[
D_4(n)=\max\{C_F:\ C_A\le4\}
\]

for unit-cost binary queries that are globally exact 50/50 on the represented
worlds.  The constructive witnesses already give

\[
D_4(12)\ge8,\qquad D_4(14)\ge10.
\]

The only remaining possibilities from the fixed-cost cap `C_F<=n-3` were 9
and 11.  Both are now excluded.

## 1. Normalize a cap-saturating fixed resolver

Assume `C_F=n-3` and choose a minimum fixed resolver `B`.  The private-pair
forest proof of the exact-balanced fixed-cost cap gives `n-3` private edges on
`n` worlds and therefore exactly three components.  At equality exact balance
forces component sizes

\[
(n/2-1,\ 2,\ n/2-1)
\]

and the two large components are stars.  Thus the private graph is
star--edge--star.

There is also no remaining freedom in a query row once its private edge is
chosen.  A star-leaf query crosses only its own edge of the private forest.  On
its large star component it therefore has counts `1` versus `n/2-2`; exact
50/50 balance forces the two other components to take the unique constant
values that fill the half.  The middle-edge row is fixed in the same way.
Hence, up to world relabelling and outcome complementation, every saturated
`B` is the canonical bundle generated by
`exact_balanced_binary_fixed_cost_cap_witness`.

## 2. External queries can be filtered using identity targets

A hypothetical adaptive policy may use declared queries outside `B`.  This is
the only issue not covered by the earlier cap-saturation-depth result.

Refine the target partition all the way to identity targets.  The canonical
bundle `B` distinguishes all represented worlds, and every member of `B` has a
Hamming-1 private pair, so its identity fixed minimum is still `n-3`.

Take one external declared balanced query `r`.  If `B+{r}` admitted an identity
resolver of size `n-4`, the same resolver would certainly resolve the original,
coarser target partition.  That contradicts the assumed original fixed minimum
`n-3`.  Therefore every external declared query must belong to the finite set
of balanced cuts that preserve the identity fixed minimum.

The exhaustive counts are:

```text
n=12: 462 balanced cuts up to complementation; 3 external cuts are safe
n=14: 1716 balanced cuts up to complementation; 3 external cuts are safe
```

So after normalization, *every possible declared query family* is contained in
`B` plus three explicitly enumerable safe cuts.

## 3. Exhaust every depth-four policy leaf partition

There are only `2^3=8` possible subsets of the safe external cuts.  For each
subset we exhaust all leaf partitions reachable by a binary policy of depth at
most four.  Stopping early is allowed at every node, so the enumeration covers
all shallower policies as well.

If an original policy resolves its target partition, its leaf partition is a
refinement of that target partition.  Every registered private edge of `B` was
cross-target originally, so every such edge must also cross policy leaves.
`B` distinguishes identity and therefore resolves every leaf partition.  It
remains only to ask whether any reachable leaf partition still has fixed
minimum `n-3` after the chosen safe external cuts are admitted.

The reachable-partition counts, indexed by the eight safe-cut subset masks, are

```text
n=12:
6727, 9018, 13152, 17471, 13152, 17471, 25750, 33918

n=14:
25750, 33918, 45730, 59687, 45730, 59687, 81188, 105064
```

For every one of these eight cases at each world count, the number of reachable
leaf partitions retaining the cap is exactly

```text
0, 0, 0, 0, 0, 0, 0, 0.
```

Thus a cap-saturating fixed resolver is incompatible with adaptive depth four,
even after allowing every external exact-balanced query that could possibly
preserve the cap.

## 4. Sharp values

Combining the impossibility with the previously certified constructive
witnesses gives

\[
\boxed{D_4(12)=8},\qquad
\boxed{D_4(14)=10}.
\]

The next unresolved size is `n=16`, where the generic bounds and the emerging
finite-size pattern suggest testing

\[
D_4(16)\in\{12,13\}.
\]

The same identity-safe-cut reduction can test the upper endpoint 13.  The
separate constructive problem is to produce an exact-balanced `(C_A,C_F)=(4,12)`
witness if the apparent `n-4` pattern continues.
