# Robust base plus early-termination premium

Status: process theorem on branch \`theory/opportunity-fitness-process-v1\`.

This note connects the sharp worst-state frontier to distribution-sensitive
expected evolutionary value.

## 1. Setup

Fix one finite task and one guaranteed-resolving adaptive policy \(\pi\).

Let

\[
T_\pi(x)
\]

be its completion cost in world \(x\), and let

\[
H_\pi
=
\max_x T_\pi(x)
\]

be its worst-path completion cost.

Let the universal fixed comparator have completion cost

\[
C_F.
\]

Let

\[
U(c)
\]

be any finite nonincreasing biological value of completing the correct action
at cost \(c\).

Let represented worlds occur with probabilities \(p_x\).

The expected adaptive performance contrast is

\[
R_{\rm exp}(\pi)
=
\sum_x p_x U[T_\pi(x)]
-
U(C_F).
\]

## 2. Theorem EP1 — exact decomposition

Add and subtract \(U(H_\pi)\):

\[
R_{\rm exp}(\pi)
=
\underbrace{
U(H_\pi)-U(C_F)
}_{\text{robust base}}
+
\underbrace{
\sum_xp_x
\left[
U(T_\pi(x))-U(H_\pi)
\right]
}_{\text{early-termination premium}}.
\]

Therefore

\[
\boxed{
R_{\rm exp}(\pi)
=
R_{\rm robust}(\pi)
+
P_{\rm early}(\pi).
}
\]

Because

\[
T_\pi(x)\le H_\pi
\]

and \(U\) is nonincreasing,

\[
\boxed{
P_{\rm early}(\pi)\ge0.
}
\]

So the expected value of one policy is exactly its worst-state guaranteed value
plus a nonnegative premium generated by worlds that terminate before its worst
path.

This premium is the missing process that the robust frontier deliberately
leaves unspecified.

## 3. Corollary EP1.1 — the minimax tree maximizes the robust base, not necessarily the total

For the minimax adaptive complexity

\[
C_A
=
\min_\pi H_\pi,
\]

a minimax-optimal policy maximizes

\[
U(H_\pi)-U(C_F)
\]

over guaranteed-resolving policies because \(U\) is nonincreasing.

But natural selection compares

\[
U(H_\pi)-U(C_F)
+
P_{\rm early}(\pi).
\]

Therefore a policy with

\[
H_\pi>C_A
\]

can still have larger expected biological value if its early-termination
premium is large enough.

The exact condition for a non-minimax policy \(\rho\) to beat one selected
minimax policy \(\pi_{\rm mm}\) is

\[
\boxed{
P_{\rm early}(\rho)
-
P_{\rm early}(\pi_{\rm mm})
>
U(C_A)-U(H_\rho).
}
\]

The right-hand side is the robust penalty paid for accepting a worse worst
case. The left-hand side is the frequency-weighted premium gained by resolving
some states earlier.

## 4. Corollary EP1.2 — expected selection can exist when the robust gap is zero

Suppose

\[
C_A=C_F.
\]

Then the sharp robust structural advantage is zero:

\[
U(C_A)-U(C_F)=0.
\]

Nevertheless any adaptive policy with worst path \(C_A\) and positive
probability of terminating earlier has

\[
P_{\rm early}>0,
\]

and therefore

\[
R_{\rm exp}>0.
\]

Thus

\[
\boxed{
C_A=C_F
\not\Rightarrow
\text{zero expected value of contingent routing}.
}
\]

The exact finite adaptive-gain theorem and expected evolutionary value answer
different questions.

## 5. Exact four-world rescue witness

Use the four-world task from
\`FITNESS_OPTIMAL_ROUTING_VS_MINIMAX.md\`.

Its universal fixed optimum is

\[
\boxed{
C_F=2.
}
\]

The core minimax optimum is also

\[
\boxed{
C_A=2.
}
\]

Therefore its robust adaptive advantage is exactly zero for every completion
value \(U\):

\[
U(C_A)-U(C_F)=0.
\]

Now use the guaranteed-resolving policy with path costs

\[
\boxed{
(1,3,3,2).
}
\]

Let world \(w_0\) have probability \(p\), and let each of the other three
worlds have probability

\[
\frac{1-p}{3}.
\]

Under exponential completion value

\[
U(t)=e^{-\mu t},
\qquad
x=e^{-\mu}\in(0,1),
\]

the adaptive expected value is

\[
J_A
=
px
+
\frac{1-p}{3}
\left(
x^2+2x^3
\right).
\]

The fixed comparator has

\[
J_F=x^2.
\]

Hence

\[
J_A-J_F>0
\]

exactly when

\[
\boxed{
p>
p^*(\mu)
=
\frac{2x}{2x+3}
=
\frac{2e^{-\mu}}
{3+2e^{-\mu}}.
}
\]

At

\[
\mu=\log2,
\]

\[
x=\frac12
\]

and therefore

\[
\boxed{
p^*=\frac14.
}
\]

So once the easy one-step world occurs more than 25% of the time, expected
contingent performance exceeds the universal fixed bundle even though

\[
C_A=C_F
\]

and the robust adaptive gain is exactly zero.

The registered example uses

\[
p=0.9,
\]

well inside this expected-value rescue region.

## 6. Corollary EP1.3 — exact expected architecture-cost ceiling for the rescue witness

Let the contingent policy pay additive architecture cost \(K\) on the same
performance scale.

Positive expected net value requires

\[
J_A-J_F>K.
\]

Solving for \(p\) gives

\[
\boxed{
p
>
p_K^*(\mu)
=
\frac{x^2+K-\frac13(x^2+2x^3)}
{x-\frac13(x^2+2x^3)}.
}
\]

Equivalently,

\[
\boxed{
p_K^*(\mu)
=
\frac{2x}{2x+3}
+
\frac{3K}
{x(1-x)(2x+3)}.
}
\]

An expected-value rescue is possible for some

\[
p<1
\]

if and only if

\[
\boxed{
K<x-x^2=x(1-x).
}
\]

Thus this single task has:

- robust cost ceiling: \(0\);
- expected cost ceiling under arbitrarily strong concentration on the easy
  state:
  \[
  K_{\rm exp,max}=x(1-x).
  \]

At

\[
\mu=\log2,
\]

\[
\boxed{
K_{\rm exp,max}=\frac14.
}
\]

So encounter-frequency structure can create a finite expected-fitness region
that is completely invisible to the robust \(C_A,C_F\) gap.

## 7. Biological interpretation

The process now has two separable components:

\[
\boxed{
\text{expected value}
=
\text{guaranteed worst-state value}
+
\text{frequency-weighted early-termination premium}.
}
\]

The robust frontier is controlled by:

- world count;
- query count;
- query arity;
- worst-path topology;
- natural-history completion value.

The early-termination premium additionally depends on:

- branch depth distribution;
- encounter frequencies;
- which worlds terminate early.

This explains why the same information architecture can support different
evolutionary outcomes across populations without changing its worst-case
routeability.

## 8. Relation to the sharp frontier

The sharp structural/value envelope remains useful because it gives the exact
distribution-free base.

For one minimax policy,

\[
R_{\rm exp}
=
R_{\rm robust}
+
P_{\rm early}.
\]

Thus empirical work can proceed hierarchically:

1. compute the exact robust base from finite topology;
2. estimate branch-specific completion times;
3. estimate world frequencies;
4. measure the early-termination premium;
5. add architecture cost.

This avoids treating either worst-case structure or encounter frequencies as a
complete explanation by itself.

## 9. Claim boundary

The algebraic decomposition itself is elementary.

The biological contribution is its use to separate two previously conflated
objects in this repository:

- exact finite robust routeability;
- frequency-dependent expected evolutionary value.

Do not claim novelty for expected utility decomposition or probability
threshold algebra by itself.
