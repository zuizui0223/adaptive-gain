# Sharp unit-cost adaptive/fixed ratio with bounded query arity

This note closes the fixed-world / fixed-query extremal problem when every
query has at most `b >= 2` deterministic outcomes and every acquisition cost is
one.

The result strictly interpolates between the already-closed binary and
unrestricted-arity cases.

## 1. Productive-tree internal-node bound

Let

\[
F_b(n,h)
\]

be the maximum number of internal-node occurrences in a rooted productive
decision tree with

- at most `n` nonempty leaves;
- worst root-to-leaf depth at most `h`; and
- between 2 and `b` nonempty children at every internal node.

Then

\[
F_b(1,h)=F_b(n,0)=0,
\]

and for `n>=2`, `h>=1`,

\[
\boxed{
F_b(n,h)
=
1+
\max_{2\le r\le \min(b,n)}
\max_{\substack{n_1+\cdots+n_r\le n\\ n_i\ge1}}
\sum_{i=1}^r F_b(n_i,h-1).
}
\]

The recurrence is exact: the root has `r` nonempty children, child `i` receives
at most `n_i` represented leaves, and conversely any maximizing collection of
child trees may be joined below one root.

For `b=2`,

\[
F_2(n,h)=\min(n-1,2^h-1).
\]

For `b>=n`, the recurrence reduces to the unrestricted-arity closed form

\[
F_b(n,h)
=
n+1-
\max\!\left(
2,
\left\lceil \frac{n}{2^{h-1}}\right\rceil
\right).
\]

## 2. Universal fixed-cost upper bound

Consider a finite deterministic unit-cost task with

- `n` represented worlds;
- `m` declared query resources;
- maximum query arity `b`; and
- adaptive optimum `C_A=h`.

Take one selected optimal adaptive tree.  Its nonempty leaves are disjoint
represented-world cells, so there are at most `n` of them.  Its internal-node
occurrences are therefore at most `F_b(n,h)`.

The number of **distinct** query identities used anywhere in the tree is no
larger than the number of internal occurrences.  Flattening those distinct
queries gives one valid fixed resolver.  Thus

\[
\boxed{
C_F\le \min\{m,F_b(n,C_A)\}.
}
\]

Hence every such task obeys

\[
\boxed{
\frac{C_F}{C_A}
\le
R_b(n,m)
:=
\max_{1\le h\le n-1}
\frac{\min\{m,F_b(n,h)\}}{h}.
}
\]

## 3. Sharpness construction

The upper bound is attained.

Take a tree `T` attaining `F_b(n,h)` for one maximizing depth `h`, and if
`m<F_b(n,h)`, repeatedly replace a deepest internal node by a leaf until exactly

\[
I=\min\{m,F_b(n,h)\}
\]

internal nodes remain.  This operation preserves both the depth and the arity
bound.

Create one physical query `q_v` for each internal node `v`.

For a leaf below child `j` of `v`, define

\[
q_v=j.
\]

For leaves outside the subtree of `v`, define `q_v=0`.  Thus `q_v` has at most
`b` distinct outcomes.  When the adaptive policy reaches `v`, asking `q_v`
selects exactly the child containing the true world.  Following the tree is
therefore a guaranteed resolving policy of cost at most `h`.

### Every internal query can be made fixed-mandatory

For each internal node `v`, let

- `r_0(v)` be the leaf reached by entering child 0 and then repeatedly child 0;
- `r_1(v)` be the analogous leaf beginning with child 1.

Add the undirected edge

\[
\{r_0(v),r_1(v)\}
\]

to a graph on the leaves.

These edges form a forest.  Inductively, all edges generated inside distinct
child subtrees lie on disjoint vertex sets, and the edge generated by `v`
connects representatives from two different child subtrees, so it cannot create
a cycle.

Two-colour that forest and use the colours as the target labels of the leaf
worlds.

For the edge belonging to `v`, query `q_v` outputs 0 and 1 on its two endpoints.
Every other query gives the same outcome on those endpoints:

- ancestors see both endpoints in the same child subtree;
- a descendant on a representative path sees the representative through its
  child 0 and the other endpoint outside its subtree, hence 0 on both;
- all other descendants see both endpoints outside and also output 0.

Therefore `q_v` is the **unique** declared separator of an opposite-target pair.
Every fixed resolver must contain all `I` internal-node queries, so

\[
C_F=I.
\]

The adaptive tree gives `C_A<=h`; therefore the constructed ratio is at least
`I/h=R_b(n,m)`.  The universal upper bound above forbids anything larger, so the
constructed task attains the bound exactly.

Extra represented worlds may be added as exact duplicates of an existing world,
and extra query resources may be added as constant queries.  Thus the construction
attains exact requested counts `n,m` whenever a smaller core is used.

Hence

\[
\boxed{
\max_{\substack{|W|=n,\ |Q|=m\\ \operatorname{arity}(q)\le b}}
\frac{C_F}{C_A}
=
R_b(n,m).
}
\]

## 4. Endpoint recovery

The theorem contains the two previously closed cases.

### Binary observations

For `b=2`,

\[
F_2(n,h)=\min(n-1,2^h-1),
\]

so maximizing over `h` gives the registered sharp binary formula.

### Unrestricted deterministic arity

For `b>=n`, the unrestricted internal-node formula is recovered, and the maximum
is attained at depth two, giving

\[
\max\frac{C_F}{C_A}
=
\max\!\left(
1,
\frac{\min\{m,1+\lfloor n/2\rfloor\}}{2}
\right).
\]

Thus bounded arity does not create a third unrelated theory: it is the exact
interpolation between the binary and unrestricted endpoints.

Implementation:

Regression checks include:

- exact reduction to the binary tree formula for `b=2`;
- exact reduction to the unrestricted tree formula for `b>=n`;
- exact reduction of the sharp ratio to both endpoint theorems;
- direct exact-solver checks of intermediate arities `b=3,4` on a small
  world/query grid; and
- independent private-pair verification in every generated witness.

The `FiniteTask` witness builder inherits the repository's 20-query solver cap;
the combinatorial theorem itself is not limited to 20 resources.

## Scope

This is a finite deterministic guaranteed-target-resolution theorem with unit
query costs and a hard maximum outcome count per query.  It does not cover
unequal costs, noisy likelihoods, calibration-changing actions, continuous
compatible sets, or scientific report licensing.
