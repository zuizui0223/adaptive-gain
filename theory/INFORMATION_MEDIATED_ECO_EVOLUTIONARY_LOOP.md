# Information-mediated eco-evolutionary loop

## Status

This note links the repository's completed deterministic structural mathematics to a minimal eco-evolutionary timescale model.

The aim is not to claim that standard population-genetic selection recurrences, autocovariance identities, eco-evolutionary feedback, cue hierarchies, or interaction-network rewiring are new. The contribution attempted here is a **cross-scale identification**:

> community state changes the structural sensing problem faced by individuals; the repository's continuation and productive-frontier objects compress that problem into an adaptive/fixed cost gap; that gap can generate state-dependent selection on sensory architecture; temporal coherence then determines whether rapid short-term evolution is retained or cancelled over longer times.

The result is a bridge among

```text
individual natural history
-> feasible cue sequence
-> target resolution
-> realized interaction
-> community state
-> structural selection environment
-> evolution
-> changed interaction process.
```

---

# 1. Four time scales

Distinguish four clocks.

\[
\tau_I
=\text{within-individual information-acquisition time},
\]

\[
\tau_C
=\text{interaction/community-update time},
\]

\[
\tau_S
=\text{persistence time of the resulting selection direction},
\]

and

\[
\tau_E
=\text{heritable evolutionary response time}.
\]

The earlier temporal-routing branch mainly concerns `tau_I`: what an individual should sense next after a previous cue.

The present note asks a different question:

\[
\boxed{
\text{when can evolution be fast over a few generations but fail to accumulate over long time?}
}
\]

That question lives at `tau_S` and `tau_E`, while being generated by processes at `tau_I` and `tau_C`.

---

# 2. A community state induces a finite sensing task

Let

\[
X_t
\]

be the ecological/community state experienced during generation `t`.

Examples of components of `X_t` can include

- pollinator guild composition;
- host or prey composition;
- predator regime;
- density and competitor state;
- phenological stage;
- local physical environment;
- the set of interaction partners currently available.

Associate to each state a finite sensing problem

\[
\mathcal T(X_t)
=
(\Omega_t,T_t,Q_t,c_t,o_t),
\]

where

- `Omega_t` is the set of represented ecological situations relevant to an individual decision;
- `T_t` is the target distinction needed before a downstream action;
- `Q_t` is the feasible cue vocabulary;
- `c_t` gives cue acquisition costs;
- `o_t` gives deterministic cue outcomes in the current exact layer.

The cue vocabulary is not assumed to be freely ordered in a biological application. Natural history can constrain which named cues are reachable after approach, contact, landing, handling, attack, or other state transitions. For such explicit named-resource questions the repository's resource-labelled continuation structures are more appropriate than the cost-only quotient.

# 3. Existing repository theorem: two structural channels

For every target-mixed state, the repository defines the productive query set

\[
P_s=\{q:q\text{ is nonconstant/productive on }s\}.
\]

The inclusion-minimal collection

\[
\mathcal H_{\min}(X)
\]

determines the fixed cost as a minimum weighted hitting set:

\[
\boxed{
C_F(X)=\tau_c(\mathcal H_{\min}(X)).
}
\]

Separately, the cost-only adaptive continuation type determines

\[
\boxed{
C_A(X)=V_A(\operatorname{Type}(X)).
}
\]

Hence the repository's joint sufficiency result gives

\[
\boxed{
\left(
\operatorname{Type}(X),
\mathcal H_{\min}(X)
\right)
\Longrightarrow
(C_A(X),C_F(X)).
}
\]

For scalar deterministic sensing cost, these are therefore two distinct channels by which a community state can alter the cost landscape experienced by an individual.

### Continuation rewiring

A community change can alter which outcome-contingent continuations remain useful, changing `C_A`.

### Frontier rewiring

A community change can alter which cue sets are globally unavoidable for a fixed phenotype, changing `C_F`.

These effects need not coincide.

The repository already contains tasks that share one adaptive continuation type and `C_A=2` while having fixed costs `C_F=3` and `C_F=2`. Thus

\[
\boxed{
\text{same adaptive decision complexity}
\not\Rightarrow
\text{same selection opportunity for contingent sensing}.
}
\]

The difference can reside entirely in fixed-side productive-frontier structure.

# 4. Individual resolution is not yet an interaction

The repository correctly stops at target resolution.

For ecological use introduce an explicit behavioral map

\[
D:
(T,Z_i,X_t,h_i)
\mapsto a_i,
\]

where `Z_i` is individual state and `h_i` its information history.

Then introduce an interaction-realization map

\[
R(a_i,X_t,Z_i)
\mapsto e_i,
\]

where `e_i` is a realized interaction event or edge.

This avoids an invalid inference:

```text
target resolved
!=
interaction necessarily occurs.
```

Natural-history sequences such as

```text
far-range cue
-> approach
-> near-range cue
-> landing/contact
-> handling cue
-> interaction
```

belong in the composition of feasible resource continuation, decision, and edge realization.

# 5. Individual behavior aggregates to community rewiring

Let

\[
M_t
\]

be the realized interaction matrix or interaction-event measure generated by all individuals during a community interval.

Conceptually,

\[
M_t
=
\mathcal A\left(\{e_{i,t}\}_i\right).
\]

The community then updates through

\[
\boxed{
X_{t+1}=F(X_t,M_t,E_t),
}
\]

where `E_t` denotes external forcing not generated by the focal interaction process.

Thus a sensory architecture can affect ecology even if its direct function is only information acquisition:

\[
\boxed{
\text{sensing policy}
\to
\text{behavior}
\to
\text{realized interaction edges}
\to
\text{community state}.
}
\]

The next generation can therefore face a different sensing task `T(X_{t+1})`.

# 6. Structural selection on sensory architecture

Compare two heritable sensory architectures.

- `A`: an outcome-contingent architecture that can realize the optimal adaptive sensing policy;
- `F`: a fixed architecture that must commit to one resolving cue bundle.

Assume that one unit of sensing cost saved contributes `lambda>0` units of log fitness and that maintaining contingent control has a constitutive log-fitness cost `kappa>=0`.

Define

\[
\boxed{
s(X)
=\log\frac{W_A(X)}{W_F(X)}
=\lambda[C_F(X)-C_A(X)]-\kappa.
}
\]

This is a minimal cost-only fitness model, not a universal fitness mapping.

Using the joint sufficiency theorem,

\[
\boxed{
s(X)
=\lambda\left[
\tau_c(\mathcal H_{\min}(X))
-
V_A(\operatorname{Type}(X))
\right]-\kappa.
}
\]

Therefore, under this model, the deterministic structural part of selection is completely determined by

```text
adaptive continuation
+
productive frontier.
```

World names, cue names, and other discarded details matter again only when one needs to map the compressed structure back to biological mechanisms or interaction identities.

# 7. Existing decomposition becomes an ecological selection decomposition

For one selected optimal adaptive tree let

- `U` be the cost of the union of all cue resources appearing anywhere in the tree;
- `C_U` be the cheapest fixed resolver restricted to that union.

The repository proves

\[
U-C_A
=
(C_F-C_A)
+(C_U-C_F)
+(U-C_U).
\]

Rearranging,

\[
\boxed{
C_F-C_A
=
(U-C_A)
-(C_U-C_F)
-(U-C_U).
}
\]

Thus the state-dependent selection coefficient can be written

\[
\boxed{
s(X)
=
\lambda\left[
\underbrace{U-C_A}_{\text{branch-exclusive opportunity}}
-
\underbrace{(C_U-C_F)}_{\text{external shortcut discount}}
-
\underbrace{(U-C_U)}_{\text{internal union redundancy}}
\right]
-\kappa.
}
\]

This gives three biologically interpretable structural channels.

### Branch-exclusive opportunity

Different natural-history branches make different later cues useful. A contingent phenotype avoids paying for mutually exclusive branches simultaneously.

### External shortcut discount

The community supplies a useful cue outside the selected sensory route that lets a fixed architecture bypass the branch structure.

Example interpretation: a new species, signal, substrate, or environmental correlate provides a broadly diagnostic shortcut.

### Internal union redundancy

The cues already present across the contingent architecture contain a cheaper fixed subset, so some apparent branch diversity does not create genuine adaptive advantage.

This decomposition is important because visually complex cue sequences do not automatically imply strong selection for conditional sensing.

# 8. Higher-order cue structure matters more than marginal cue summaries

The repository has exact negative results showing that

```text
continuation type + resource-orbit capacities
```

and

```text
continuation type + per-resource role profiles
```

are insufficient to recover `C_F`.

Ecologically, this warns against predicting the value of contingent sensing from marginal cue statistics alone.

Quantities such as

- how often a cue appears;
- how many states it is informative in;
- its average information content;
- its marginal role frequency

need not determine the fixed sensing burden.

The higher-order co-occurrence structure of cue obligations can matter.

This provides a possible bridge to community ecology: two communities with similar marginal cue prevalences can exert different selection on sensory routing because the **configuration** of irreducible cue obligations differs.

# 9. Existing extremal mathematics gives evolutionary implications

## 9.1 Many ecological branches can strongly favour shallow conditional sensing

For the repository's unit-cost `k`-branch family,

\[
C_A=2,
\qquad
C_F=k+1.
\]

Therefore under the minimal fitness map

\[
\boxed{
s_k
=\lambda(k-1)-\kappa.
}
\]

The individual conditional policy remains only two cue acquisitions deep, while the fixed sensory burden increases linearly with the number of branch-specific ecological situations.

Thus

\[
\boxed{
\text{large selection for conditional architecture}
\not\Rightarrow
\text{deep within-individual decision sequence}.
}
\]

A shallow natural-history decision can be strongly favoured simply because many mutually exclusive interaction contexts exist.

## 9.2 Binary cues do not remove the effect

For routing depth `d`, the binary-only family has

\[
C_A=d+1,
\qquad
C_F=2^d.
\]

Hence

\[
\boxed{
s_d
=\lambda(2^d-d-1)-\kappa.
}
\]

So a large structural selection opportunity does not require high-arity or unusually rich individual observations.

## 9.3 Frontier edge count can limit the opportunity; frontier rank cannot

With minimal productive-frontier edge count capped by `E`, the repository proves `C_F<=E` under unit costs.

For an unresolved mixed target requiring positive adaptive cost,

\[
C_F-C_A\le E-1,
\]

so this fitness model gives

\[
\boxed{
s(X)\le\lambda(E-1)-\kappa.
}
\]

By contrast, a positive cap on maximum frontier-edge size does not improve the repository's extremal adaptive/fixed ratio: the sharp witnesses already use singleton frontier edges.

The ecological suggestion is structural rather than literal:

> the number of distinct irreducible cue obligations can constrain the maximum benefit of routing, while merely limiting how many cues occur in one obligation need not do so.

# 10. Exact population-genetic bridge

Let `p_t` be the frequency of contingent architecture `A` in a haploid population.

Under viability selection with relative log fitness `s(X_t)` and no mutation, migration, or frequency dependence,

\[
\frac{p_{t+1}}{1-p_{t+1}}
=
\frac{p_t}{1-p_t}e^{s(X_t)}.
\]

Therefore

\[
\boxed{
\operatorname{logit}(p_{t+1})
=
\operatorname{logit}(p_t)+s(X_t).
}
\]

Across `H` generations,

\[
\boxed{
\operatorname{logit}(p_H)-\operatorname{logit}(p_0)
=
\sum_{t=0}^{H-1}s(X_t).
}
\]

This exact identity creates the timescale distinction.

Define evolutionary selection activity

\[
\boxed{
A_H=\sum_{t=0}^{H-1}|s(X_t)|
}
\]

and retained directional change in log odds

\[
\boxed{
R_H=\left|\sum_{t=0}^{H-1}s(X_t)\right|.
}
\]

Then

\[
0\le R_H\le A_H.
\]

The retention ratio is

\[
\boxed{
\mathcal R_H
=\frac{R_H}{A_H}
}
\]

when `A_H>0`.

A population can therefore have large per-generation evolutionary activity while retaining almost no long-horizon directional displacement.

# 11. Exact burst-with-stasis switching witness

Let two community states induce structural gaps

\[
g_+>g_-\ge0.
\]

Their selection coefficients are

\[
s_+=\lambda g_+-\kappa,
\qquad
s_-=\lambda g_- -\kappa.
\]

If

\[
\lambda g_-<\kappa<\lambda g_+,
\]

then selection reverses direction between community states.

Choose the midpoint cost

\[
\boxed{
\kappa
=\lambda\frac{g_++g_-}{2}.
}
\]

Then

\[
s_+=+\delta,
\qquad
s_-=-\delta,
\]

where

\[
\delta
=\lambda\frac{g_+-g_-}{2}>0.
\]

If the community alternates exactly,

```text
X+ -> X- -> X+ -> X- -> ...
```

then every generation experiences nonzero selection,

\[
A_{2n}=2n\delta,
\]

but

\[
\boxed{
R_{2n}=0
}
\]

and, more strongly,

\[
\boxed{
p_{2n}=p_0.}
\]

Thus the minimal model gives

\[
\boxed{
\text{rapid reversible short-term evolution}
+
\text{exact long-term stasis}.
}
\]

This is not caused by weak selection. It follows exactly in log-odds coordinates from selection reversal.

An executable repository witness uses

- a strict routing task with `(C_A,C_F)=(2,3)`, hence `g_+=1`;
- a no-gain routing/bypass control with `(C_A,C_F)=(2,2)`, hence `g_-=0`;
- `kappa=lambda/2`.

The two states have the same adaptive cost `C_A=2` but opposite selection on whether contingent-control architecture is worth maintaining.

# 12. Stochastic selection coherence and long-term retention

Let the state-dependent selection coefficient have zero mean and stationary autocovariance

\[
\gamma(k)=\operatorname{Cov}(s_t,s_{t+k}).
\]

Then the standard partial-sum identity gives

\[
\boxed{
\operatorname{Var}\left(\sum_{t=0}^{H-1}s_t\right)
=
H\gamma(0)
+2\sum_{k=1}^{H-1}(H-k)\gamma(k).
}
\]

So the long-horizon retained evolutionary displacement is controlled by **signed selection coherence across time**, not by the instantaneous magnitude of selection alone.

For a symmetric two-state Markov selection process

\[
s_t=s_0 Z_t,
\qquad Z_t\in\{-1,+1\},
\]

with

\[
\operatorname{Corr}(Z_t,Z_{t+k})=\phi^k,
\]

we obtain

\[
E\left[\left(\sum_{t=0}^{H-1}s_t\right)^2\right]
=s_0^2F_H(\phi),
\]

where

\[
\boxed{
F_H(\phi)
=
H+2\sum_{k=1}^{H-1}(H-k)\phi^k.
}
\]

For `phi!=1`,

\[
\boxed{
F_H(\phi)
=
\frac{H(1-\phi^2)-2\phi+2\phi^{H+1}}
{(1-\phi)^2}.
}
\]

At `phi=1`, `F_H=H^2`.

The RMS retention ratio relative to `H|s_0|` units of per-generation activity is

\[
\boxed{
\mathcal R_H^{RMS}
=
\frac{\sqrt{F_H(\phi)}}{H}.
}
\]

Special cases:

```text
phi = 1    -> full directional retention
phi = 0    -> RMS retention ratio = 1/sqrt(H)
phi = -1   -> exact cancellation for even H
```

For `|phi|<1`,

\[
F_H(\phi)
\sim
H\frac{1+\phi}{1-\phi},
\]

so

\[
\mathcal R_H^{RMS}
\sim
\sqrt{\frac{1+\phi}{1-\phi}}\,H^{-1/2}.
\]

Under zero-mean fluctuating selection, evolutionary activity can therefore remain high while directional retention becomes small over long horizons.

A nonzero mean selection component changes this conclusion: the mean contributes a linear `H` drift in log odds and can dominate long-term direction.

# 13. A cross-scale temporal asymmetry

The temporal-routing branch found, for its symmetric within-episode model,

\[
G_{route}\propto|\phi|.
\]

Both positive persistence and perfect alternation are useful because both make the identity of the next useful cue predictable.

The evolutionary retention layer is different.

Directional accumulation depends on the **sign** of temporal selection coherence.

Therefore two systems can have equal within-individual temporal predictability

\[
|\phi|=1
\]

but opposite long-term evolutionary consequences:

### Persistent environment

\[
\phi=+1:
\]

- routing predictability is maximal;
- selection direction is persistent;
- long-term directional retention is maximal.

### Perfectly alternating environment

\[
\phi=-1:
\]

- routing predictability is also maximal;
- an individual can exploit the alternation perfectly;
- but if community-mediated selection reverses with the alternation, even-horizon evolutionary change cancels exactly.

Thus

\[
\boxed{
\text{predictability for individual adaptive behavior}
\ne
\text{persistence required for long-term evolutionary accumulation}.
}
\]

This is the central cross-timescale insight of the present construction.

# 14. Closing the eco-evolutionary loop

Let the frequency of sensory architecture influence individual information paths and therefore the realized interaction matrix:

\[
M_t
=
M(X_t,p_t,Z_t).
\]

Then

\[
X_{t+1}=F(X_t,M_t,E_t),
\]

and the next community state changes

\[
\operatorname{Type}(X_{t+1}),
\qquad
\mathcal H_{\min}(X_{t+1}),
\]

which changes

\[
s(X_{t+1}).
\]

The minimal closed loop is therefore

\[
\boxed{
X_t
\to
\text{sensing task}
\to
(C_A,C_F)
\to
\text{individual behavior}
\to
M_t
\to
X_{t+1}
\to
s(X_{t+1})
\to
p_{t+1}
\to
\text{future sensing and interactions}.
}
\]

The arrows from target resolution to behavior and from behavior to interaction must be supplied by biological natural history; they are intentionally not inferred from the deterministic resolution theorem alone.

# 15. What this suggests empirically

The theory suggests measuring several things at different scales instead of one generic evolutionary rate.

### Individual scale

- feasible cue order;
- branch-contingent cue use;
- cue acquisition cost;
- alternative shortcuts;
- repeated or redundant cue channels.

### Interaction scale

- which decision branches actually generate approach, attack, mating, oviposition, pollination, or abandonment;
- rewiring of realized interaction edges after cue or state changes.

### Community scale

- changes in the structural sensing task generated by partner composition;
- continuation rewiring versus productive-frontier rewiring;
- appearance/disappearance of external shortcuts.

### Evolutionary scale

- generation-specific log-fitness or selection differential on sensory architectures;
- total short-term selection activity;
- signed temporal autocorrelation of selection;
- retained change across increasing temporal windows.

A strong empirical signature of the proposed mechanism would be

```text
large within-window allele/trait movement
+
frequent selection reversals
+
low long-horizon retained displacement
+
community-state dependence of the structural sensing gap.
```

# 16. Scope boundary

The current bridge is deliberately minimal.

It does not yet include

- diploid dominance;
- mutation, migration, drift, or recombination;
- frequency-dependent fitness inside the population-genetic recurrence;
- polymorphic target maps;
- stochastic or continuous sensing tasks on this branch;
- explicit ecological population dynamics;
- evolution of the community transition kernel itself;
- speciation or macroevolutionary lineage birth/death.

The exact contribution of this branch is narrower:

1. reuse existing `C_A`, `C_F`, continuation, productive-frontier, and decomposition results as a structural selection environment;
2. distinguish evolutionary activity from retained evolutionary change;
3. exhibit an exact alternating-community witness with rapid reversible evolution but zero two-generation net change;
4. expose the sign-sensitive temporal filter that separates individual predictability from long-term evolutionary accumulation.
