# General local evolutionary response in the structural feedback loop

## Status and claim boundary

The parent endogenous-feedback branch uses one explicit evolutionary update:

\[
\operatorname{logit}(p_{t+1})
=
\operatorname{logit}(p_t)+s(q_t).
\]

That update is useful because it is exact for the stated haploid model, but it fixes the local evolutionary persistence and selection responsiveness to one.

This note removes that special choice and asks which feedback results depend only on the **local response derivatives** of evolution.

The two-dimensional Jacobian/Jury algebra below is standard. The repository does not claim new local dynamical-systems theory. The repository-specific contribution is that the state-selection slope may itself be generated by the exact adaptive/fixed sensing structure through

\[
\Delta s=\lambda\Delta g.
\]

---

## 1. Generic local evolutionary update

Let `x_t` be any scalar evolutionary coordinate for which a differentiable local update can be written

\[
x_{t+1}=F(x_t,s(q_t)).
\]

At an interior equilibrium `(x*,q*)`, assume

\[
s(q^*)=0,
\qquad
F(x^*,0)=x^*.
\]

Define

\[
\boxed{
\alpha
=\left.\frac{\partial F}{\partial x}\right|_*}
\]

as **intrinsic evolutionary persistence**, and

\[
\boxed{
\beta
=\left.\frac{\partial F}{\partial s}\right|_*}
\]

as **local selection responsiveness**.

The main domain used here is

\[
0\le\alpha\le1,
\qquad
\beta\ge0.
\]

`alpha=1` means that, in the absence of current selection, the evolutionary coordinate is locally carried forward without intrinsic decay. `alpha<1` means there is local restoring/mean-reverting tendency in the chosen coordinate.

No claim is made that every biological evolutionary process is exactly first-order scalar in this sense. This is a local reduction.

---

## 2. Generic ecological feedback derivative

Let community occupancy relax as

\[
q_{t+1}
=\phi q_t+(1-\phi)Q(x_t),
\]

with

\[
0\le\phi<1.
\]

Define

\[
\boxed{
e=Q'(x^*)}
\]

as the ecological feedback slope with respect to the chosen evolutionary coordinate.

The state-specific selection signal has local slope

\[
\boxed{
\Delta s
=\left.\frac{ds}{dq}\right|_*.
}
\]

In the two-state affine selection model of the parent branch this is exactly

\[
\Delta s=s_+-s_-.
\]

---

## 3. Exact generalized Jacobian

Linearization gives

\[
\boxed{
J=
\begin{pmatrix}
\alpha & \beta\Delta s\\
(1-\phi)e & \phi
\end{pmatrix}.
}
\]

Define the generalized closed-loop gain

\[
\boxed{
G=-\beta\Delta s\,e.
}
\]

For the usual case `beta>0`, `Delta_s>0`:

- `e<0` gives restoring negative ecological feedback and `G>0`;
- `e>0` gives reinforcing positive ecological feedback and `G<0`.

The trace and determinant are

\[
\boxed{
T=\alpha+\phi,
}
\]

\[
\boxed{
D=\alpha\phi+(1-\phi)G.
}
\]

Thus the generalized local system is controlled by three dimensionless quantities:

```text
alpha   intrinsic evolutionary persistence
phi     community memory
G       closed-loop eco-evolutionary gain
```

---

## 4. Exact stability interval

For

\[
0\le\alpha\le1,
\qquad
0\le\phi<1,
\]

the Jury expressions are

\[
1-T+D
=(1-\phi)(1-\alpha+G),
\]

\[
1+T+D
=(1+\alpha)(1+\phi)+(1-\phi)G,
\]

\[
1-D
=1-\alpha\phi-(1-\phi)G.
\]

The middle condition is automatic throughout the biologically relevant interval once the other two are satisfied. Therefore

\[
\boxed{
\alpha-1
<G
<
\frac{1-\alpha\phi}{1-\phi}.
}
\]

Define

\[
\boxed{G_-=\alpha-1}
\]

and

\[
\boxed{
G_+=\frac{1-\alpha\phi}{1-\phi}.
}
\]

Then local asymptotic stability is exactly

\[
\boxed{G_-<G<G_+.}
\]

---

## 5. New qualitative consequence relative to the haploid special case

When

\[
\alpha=1,
\]

we have

\[
G_-=0.
\]

Therefore any reinforcing feedback `G<0` is locally non-restoring, exactly as in the parent haploid-logit model.

But when

\[
\alpha<1,
\]

then

\[
G_-<0.
\]

Hence a finite range of reinforcing positive ecological feedback can remain locally stable:

\[
\boxed{
\alpha-1<G<0.
}
\]

The interpretation is not that positive feedback has become negative. Instead, intrinsic evolutionary damping in the chosen coordinate is strong enough to absorb a weak reinforcing ecological loop.

This distinction matters when extending the theory beyond a pure allele-frequency logit with no intrinsic local decay.

## 6. Oscillation threshold

The characteristic discriminant is

\[
\Delta_J
=(\alpha+\phi)^2
-4[\alpha\phi+(1-\phi)G].
\]

It factorizes as

\[
\boxed{
\Delta_J
=(\alpha-\phi)^2
-4(1-\phi)G.
}
\]

Therefore the eigenvalues are complex exactly when

\[
\boxed{
G>
G_{osc}
:=
\frac{(\alpha-\phi)^2}{4(1-\phi)}.
}
\]

Inside the stability interval:

```text
G_- < G <= G_osc
    stable nonoscillatory return

G_osc < G < G_+
    stable damped oscillation
```

Because `G_osc>=0`, the weak positive-feedback part of the stable interval created by `alpha<1` is always nonoscillatory.

---

## 7. Upper boundary is again a unit-circle crossing

At

\[
G=G_+,
\]

we have

\[
D=1.
\]

For the stated domain,

\[
\alpha+\phi<2
\]

except for the excluded singular endpoint `alpha=phi=1`. Hence the upper boundary is a conjugate unit-circle crossing with

\[
\boxed{
\cos\theta_c
=\frac{\alpha+\phi}{2}.
}
\]

The critical local period is

\[
\boxed{
T_c
=\frac{2\pi}{\arccos[(\alpha+\phi)/2]}.
}
\]

The parent formula is recovered by setting `alpha=1`.

---

## 8. Generalized critical slowing near the upper boundary

Inside the stable damped region,

\[
\rho^2=D
=\alpha\phi+(1-\phi)G.
\]

Using the definition of `G_+`,

\[
\boxed{
\rho^2
=1-(1-\phi)(G_+-G).
}
\]

Thus

\[
\boxed{
\tau_{damp}
=-\frac{2}{\log[1-(1-\phi)(G_+-G)]}
}
\]

and near the upper boundary

\[
\boxed{
\tau_{damp}
\sim
\frac{2}{(1-\phi)(G_+-G)}.
}
\]

So the critical-slowing result survives the generalized evolutionary response. What changes is the structural distance to the relevant upper boundary.

## 9. Exact recovery of the parent haploid-logit model

Take

\[
x=z=\operatorname{logit}(p).
\]

The parent evolutionary update is

\[
z_{t+1}=z_t+s(q_t),
\]

so

\[
\alpha=1,
\qquad
\beta=1.
\]

The ecological target is

\[
Q(z)
=q_0+\eta[p(z)-1/2],
\]

so

\[
e
=\eta p^*(1-p^*).
\]

Therefore

\[
G
=-\Delta s\,\eta p^*(1-p^*)
=L.
\]

The generalized thresholds become

\[
G_-=0,
\]

\[
G_+=1,
\]

and

\[
G_{osc}
=\frac{1-\phi}{4}.
\]

Hence every exact local result in the parent phase diagram is recovered.

## 10. Structural sensing mathematics enters unchanged upstream

Under the continuous structural lift,

\[
\Delta s=\lambda\Delta g.
\]

Therefore

\[
\boxed{
G
=-\beta\lambda\Delta g\,e.
}
\]

The exact finite sensing theory still determines

\[
\Delta g
=[(C_F-C_A)_+-(C_F-C_A)_-].
\]

The new evolutionary-response layer changes only how strongly that structural selection contrast is converted into dynamical feedback.

Thus the full local chain becomes

```text
natural-history finite sensing structure
    -> exact Delta_g
    -> state-selection contrast lambda*Delta_g
    -> evolutionary response beta
    -> ecological effect slope e
    -> generalized loop gain G
    -> local eco-evolutionary phase
```

## 11. Interpretation of alpha and beta

`alpha` and `beta` are **local derivatives**, not universal biological constants.

Depending on the chosen evolutionary coordinate, they may summarize different mechanisms:

- persistence of an allele-frequency or transformed frequency coordinate;
- local quantitative-trait carryover;
- a response coefficient proportional to available heritable variation;
- a local behavioral/cultural evolutionary response, if that is the modeled inherited state.

The note does not equate these mechanisms. They share only the same local scalar response form.

A biological application must state the coordinate `x`, the selection signal `s`, and why the local derivatives are meaningful for that system.

## 12. Prior-art boundary

The following are not claimed as new:

- linearization of a coupled ecological/evolutionary map;
- 2x2 Jury stability criteria;
- trace/determinant phase classification;
- critical slowing near a unit-circle boundary;
- generic response coefficients in local dynamical systems.

The repository-specific contribution is narrower:

\[
\boxed{
\text{exact finite sensing gap}
\to
\text{state-selection contrast}
\to
\text{generalized eco-evolutionary loop gain}.
}
\]

This generalization shows which conclusions of the structural feedback theory survive after removing the particular haploid log-odds update, and which conclusion changes: weak positive feedback need not destabilize a system with intrinsic evolutionary damping.

---

## 13. Scope

This remains a local, deterministic, scalar evolutionary response coupled to one scalar community state.

It does not yet include

- multivariate quantitative genetics;
- linkage or explicit diploid genotype dynamics;
- mutation, migration, or drift;
- stochastic ecological or observation noise;
- multiple evolving species;
- global nonlinear bifurcation classification.

The purpose of this layer is not maximal realism. It is to show that the repository's structural sensing result does not fundamentally depend on the one special haploid logit update.
