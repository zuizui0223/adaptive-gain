# Stage 8b — trip- and interruption-conditioned lag-association null for individually tagged bees

**Timestamp 2026-10-28.** This is a **post-hoc exploratory control**, decided AFTER observing Stage 8 M0→M1 gain +0.0515255 nats per next touched-flower orientation; no claim of prospective confirmatory preregistration. All numeric permutation settings and scientific gates below are committed **before inspecting Stage 8b shuffled data outcomes**.

## Specific rival explanation
In Cambridge Apollo original 2023 3-colony experiment, source 36 completed individually tagged bees' prior H/V touched-flower orientation predicted next H/V type on held-out late micro-rough trips. This might be **within-bout latent composition persistence**, not within-sequence Markov dependence. Specifically a foraging trip dominated by one flower type can produce a strong lag correlation without prior choice changing future choice.

A **conditional lag-null** should fix each original test bee's next-flower sequence, per-trip composition and all earlier fitted models while assigning prior state labels differently within the *same genuine source continuous handling segment*. The question becomes: is the alignment of previous flower type / recorded drink with next type nonexchangeable **within true uninterrupted source visit segments**, beyond trip-level resource composition?

- Reuse **exactly unchanged Stage 8** original native action→12,064 visit episode reconstruction, author-excluded incomplete bees (Yellow 4, Green 47), **36 complete bees from 3 original colonies**; micro-rough test phase, legitimate adjacent visit pairs within same source `Foraging trip`, excluding rest/boutStartStop gaps. Original source `Time(ms)` is action duration, *not* a timestamp; `Flower ID` is per-interaction group, *not* physical ID. No resampling, changing hyperparameters or selecting colony/bee subsets based on outcomes.

## Conditional permutation unit and two fixed tests
First group each bee's original **heldout adjacent-pair records** by `(colony,bee,Foraging trip)`, then split into uninterrupted segments: successive pair records share the same original visited source episode only where `next_pair.previous_episode_first_source_row == prior_pair.next_episode_first_source_row`. Never join different bouts, rest interruptions, original bees or surface phases. The observed outcome for each transition is the next touched orientation `Y_t = horizontal/vertical`.

**Main null N1 — trip/segment-conditioned previous orientation:**
- Hold **all actual next choices Y_t, visit counts, source trip IDs, source row positions, bee and colony identity, original train/test split and fitted M0/M1/M2 models unchanged**.
- Within each eligible same-bee, same-bout, same-contiguous-episode segment, uniformly shuffle the **joint previous state (previous H/V orientation, previous observed drink-action yes/no)** between the genuine original adjacent transition records. This preserves exact predecessor state type counts and drink counts, within source uninterrupted segment, but breaks their precise original **alignment** with following H/V choices. It does not construct a physically possible flight path; it is a conditional statistical null only.
- Compute per-bee heldout log-loss NLL(M0)−NLL(M1) in nats/decision; M0 must be *bit-for-bit unchanged* under this shuffle. Summarize the **equal colony weight mean of equal-bee effects** across the 3 source colonies, and 36 individuals. Fixed **199 permutations** with seed `20261028`. One-sided positive-tail Monte Carlo p `(1 + # shuffled N1_gain ≥ actual N1_gain)/(199+1)`; minimum p=.005.

**Secondary null N2 — prior drink conditional on same previous orientation:**
- Again retain all genuine following H/V outcomes, original training and prior H/V orientation. Within each `(bee,Foraging trip,uninterrupted segment,previous orientation)` subgroup, shuffle **only the previous observed drink yes/no bit** across heldout adjacent transitions, preserving original conditional drink counts. M1 predictions are therefore exactly fixed; M2 predictions use the shuffled prior drink label.
- Score M1−M2 gain on the exact same original heldout 1,234 decisions. Same 199 permutations and seed `20261028`. This is an **additional exploratory check**, NOT the main preregistered experiment outcome. The source does not record actual nectar intake volume or a randomized experience condition.

### Support gates
All 36 completed bees, 3 original colonies and exactly 1,234 heldout true next-choice edges must reconcile. The **primary N1 test** requires ≥200 heldout edges in exchangeable uninterrupted segments containing ≥2 distinct previous-orientation labels **and at least 10 individual bees with ≥5 such edges**. If N1 unsupported, NO_GO (no p-value); do not relax segment boundaries or compare random rows. The secondary N2 test requires ≥100 heldout edges in exchangeable `previous_orientation` subgroups containing both drink outcomes across ≥10 original bees (≥5 eligible edges each), else NO_GO. For each shuffle record how many previous labels actually changed and eligible sets. The original 36-bee predictor gains must match Stage 8 results within floating tolerance (0.0515255104 M0→M1 and 0.00475076985 M1→M2) before shuffling.

## Interpretive firewall
A positive N1 comparison identifies non-exchangeable lag alignment beyond fixed within-trip segment-level state margins; it is **not causal evidence of motor inertia or cognitive memory**, because same source flower ep ID is not a physical spatial location and unobserved choice environment / time-dependent state remains. A null N1 would indicate the previously observed M0→M1 gain could be explained by **within-trip/segment composition and action-sequence constraints** rather than individual learned memory. N2 likewise can only speak to **source-coded drink-action predictive association**, not reward efficacy or information access cost. Neither data nor permutation manipulates ambient wind, flower cue availability, individual route geometry, competition or reproductive fitness.

Do not use the across-3-colonies source as 36 independent colonies; the 199 randomized datasets are conditional null replicates, not 199 new experiments. Report negative as well as positive results and **stop** trying a different time/bin/trip/shuffle segmentation to chase statistical significance. V5/V6 frozen manuscript and Stage 8 original source/results remain unchanged.
