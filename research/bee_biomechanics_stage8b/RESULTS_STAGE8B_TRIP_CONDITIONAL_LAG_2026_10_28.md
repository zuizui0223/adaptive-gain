# Stage 8b original-data result — does actual previous flower-choice order predict beyond trip composition?

**Date 2026-10-28. Status: ORIGINAL CAMBRIDGE SOURCE VERIFIED; 199+199 predeclared conditional statistical permutations executed successfully.** The observed prior-flower **orientation** alignment contains a small residual predictive gain **after holding fixed each bee's trip/continuous-segment predecessor-state composition and all actual next choices**. Most of the original apparent predictive improvement is also generated by group-level within-trip/segment composition in the constrained null. The additional **previous observed *Drink action** has no supported residual conditional association. The entire Stage 8b test is **post-hoc exploratory relative to the positive Stage8 M0→M1 finding**.

The unchanged Stage8 source adapter reconstructs **12,064 actual touched flower episodes**, **7,247 slippery micro-rough test episodes**, and **6,311 true within-bout test next-orientation edges** among all 38 source bees, with original rest and bout markers respected. All Stage8b observations come from the same strictly future **1,234 later true next H/V source choices** in 36 bees, with the same earliest ceil(70%) *foraging trips* used to train α=.5 bee stationary M0, β=10 previous-orientation M1 and γ=10 previous-orientation+drink-action M2. The procedure explicitly verifies the prior numerical results before evaluating either new conditional null.

## 2. Frozen statistical control and exact denominators

[Stage8b source-role/conditional-lag control protocol](PROTOCOL_CONDITIONAL_BOUT_LAG_NULL_2026_10_28.md) committed **before Stage8b permutation outcomes**, but after the positive Stage8 results.

The original test pairs are partitioned into **176 original uninterrupted adjacent-episode segments** defined by:
- same original bee, colony, `Foraging trip` and micro-rough surface;
- two successive recorded pairs join only if the previous pair's original **next touched episode's source row index equals the following pair's original previous episode's source row index**;
- original `rest`, `boutStartStop` and real trip boundaries remain severed, no fabrication of animal flights, spatial flower IDs or cross-bout transitions.

Exactly **199 fixed-seed (20261028)** permutations per statistical test preserve every **actual next horizontal/vertical outcome**, whole 36-bee original test population and its complete trip/source-row order, original early-day fitted model parameters and source predecessor state counts in every uninterrupted source segment. Only the original alignment of the previous predictors with the next observed flower type is randomized. This **does not construct physically possible bee movement routes**; it is a conditional statistical exchangeability null.

- **N1 primary previous-orientation null:** jointly permute source previous flower H/V orientation and recorded drink label **within each uninterrupted segment**, preserving each segment's predecessor H/V and drink multiset. Although all 1,234 actual decisions are scored, only **544 original test edges from 18 actual source bee tags** have genuinely exchangeable previous orientations in their segment and pass predeclared ≥200 edges/≥10 bees×5 support. Remaining source edges remain unchanged in all pseudo-data; do not treat every edge as independently permutable.
- **N2 secondary previous-drink null:** keep each actual previous orientation and next outcome fixed and shuffle previous drink only inside original `(bee,source trip,uninterrupted segment,previous orientation)` cells. **852 original test edges across 34 source bees** meet ≥100 edges/≥10 bees×5 source variation; the M1 predictions remain strictly unchanged in every randomization.
- Model probabilities were frozen, **no refitting or hyperparameter search** on randomized/heldout data. The original M0 log loss was identical across all tests and both shuffles, and the M1 log loss was identical across the secondary N2 shuffles.

## 3. Original measured lag-alignment versus trip-conditioned null

All gains are per original next-touched H/V decision in **nats**, summarized with **equal bee weights and equal original three-colony weights** (each original colony contributed 12 complete bee tags). Source original model M0→M1 was **+0.0515255104** and primary prior drinking-action M1→M2 was **+0.0047507698**, both exactly reproduced before the new analysis.

| Comparison | Actual frozen-model gain | Conditional shuffle mean gain (199) | **Actual−shuffle mean** | 1-sided conditional Monte Carlo p |
| --- | ---: | ---: | ---: | ---: |
| **N1 previous orientation**: M0→M1 | **+0.0515255** | **+0.0445011** | **+0.0070244** | **0.005 (smallest 1/200)** |
| **N2 previous recorded drinking**: M1→M2 | +0.0047508 | +0.0042644 | +0.0004864 | **0.355** |

For N1, the randomized 5th–95th gain range is 0.0409039–0.0482369; the observed 0.0515255 is larger than all **199 predeclared randomizations** (sample max 0.0508986). Mean number of predecessor-state labels actually reassigned per shuffled sample: 462.83 out of 1,234 actual test pairs.

For N2, randomized 5th–95th range is 0.0023444–0.0063498; actual +0.0047508 lies within this conditional null, which is inconsistent with a generally strong immediate previous-drink incremental predictor. Mean label reassignments: 321.73.

**Interpretive nuance:** the N1 mean randomized gain 0.044501 is **approximately 86.4% of the actual raw 0.051526 predictive gain**, but this is **not a causal percentage explained by bout preference**. It says that much of the apparent raw temporal predictive gain occurs even when the alignment of within-segment predecessor labels with fixed later choices is destroyed. The residual **+0.00702** is a small but detectable *conditional lag-alignment* signal under this explicitly constrained within-source null. The p=.005 is limited by the 199 Monte Carlo samples, and post-hoc reasoning prevents representing it as a prespecified independent hypothesis confirmation.

N2 drink residual directions split 2 positive and 1 negative. **Three colonies do NOT establish a population-universal bee behavioral mechanism, even though source bees are individually tagged and 1,234 valid transitions are observed.** Per-colony source data and the original source's treatment factors must remain separate from the claimed inference unit.

## 5. What survives Stage 4 → Stage 8b evidence hierarchy

- **Stage 4 (2019 single colony, ten flowers):** the physical previous flower ID improves next destination prediction versus each bee's stationary choice preferences. Stage5/6 show that physically measured geometric distance and incoming endpoint-chord direction explain a large part of that apparent memory effect; extra first-order history did not give a consistent directional destination gain.
- **Stage 7b (2026 independent robotic flowers, 18 colonies):** group-level reward-use **5-minute local temporal smoothness** in 16 qualifying colonies beyond constrained hour-level reward composition and effort. Source contains **no individually tagged bees**, so group-level persistence cannot be interpreted as individual foraging memory or social influence.
- **Stage 8 (2023 Cambridge, three colonies, 36 tagged bees):** last touched flower *orientation* predicts next orientation beyond static individual preference, but previous observed drinking action added a very small effect and a difficult vertical-hover sensitivity was negative.
- **Stage 8b new result:** after conditioning on each genuine bee/trip/rest-bounded segment's predecessor-state composition, there is still a **small, source-conditional orientation lag alignment (+0.00702 nats)**, while **drink-outcome lag alignment is indistinguishable from the restricted null (p=.355)**. Most apparent raw Stage8 orientational predictive gain is shared with the within-bout/segment state composition.

**Research implication:** temporal order may be predictive even when static preferences and original foraging-trip state composition are controlled, but **physical flower locations, continuity of motor movement, current flower occupancy, perceptual cue order and source reward values remain unobserved**. The evidence supports a bounded *organizational/time-series* claim, not a fully identified causal information-routeability mechanism. Since a separate source experiments on physical handling cost but not randomized per-visit cue-reveal, neither a causal conflict/payoff optimum nor `C_A,C_F` can be inferred.

## 6. Scientific stop and next true experiment

No additional arbitrary trip partition, source flower subgroup, posthoc γ/β change, or alternative randomization window is warranted in this source merely to improve significance. The **remaining missing design** is simultaneous source multi-colony **individually identified bees**, fixed known physical flower position/visibility, manipulated **ordering of cue/reward availability**, measured individual flight/handling cost and actual reward intake. A factorial intervention varying what cues are observable *when* while holding original flower geometry and nectars otherwise constant would distinguish geometric movement, contextual resource preference and the causal value of information order.
