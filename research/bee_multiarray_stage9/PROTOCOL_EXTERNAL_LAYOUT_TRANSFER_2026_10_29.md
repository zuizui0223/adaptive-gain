## New independent data and biological difference
Klein, S., Pasquaretta, C., Barron, A. B., Devaud, J.-M. & Lihoreau, M. (2017). *Inter-individual variability in the foraging behaviour of traplining bumblebees*. **Scientific Reports** 7:4561, DOI **https://doi.org/10.1038/s41598-017-04919-8**, PMC5496863. Two original colonies, **29 individually tagged foragers**, all tested across **three sequentially presented experimental arrays**, each consisting of four physical reward flowers in a different arrangement and conspicuous spatial landmarks. Each bee undertook **20 recorded consecutive foraging bouts per array**. The original article identifies source `Supplementary Dataset S1`, **41598_2017_4919_MOESM2_ESM.csv**, as the complete flower visitation sequences, and source Dataset S2 **41598_2017_4919_MOESM3_ESM.csv** for companion information. The original paper already demonstrated efficient trapline development, individual variability and different speed/route fidelities; those findings must **not** be claimed as newly discovered.

New question: **Does an incoming-chord direction rule, whose *dimensionless* strength was estimated in a separate 2019 single-layout experiment, transfer to three different 2017 flower-layout geometries without re-estimating the directional coefficient?** This tests *transportability of a geometrically defined movement-prediction rule*, not source bee memory, cognition, cue accessibility or direct measured flight bearing.

## Gate 3 — frozen truly independent directional-rule test
Only if Gates 1 and 2 both pass:
- **Original within-bout true triplets** `A→B→C` with `A≠B` and `B≠C`. No invented across-bout/array/nest transitions or shortcuts across unrewarded revisits; retain all original visit counts in QA. Predict C given original prior physical A,B and the four *physically present* options (three alternatives conditional on next≠B), which are not necessarily simultaneously seen.
- For each original bee in each original array, train a **stationary four-flower visit prior**, α=0.5 per flower, on first **15** source bouts; test **final 5** source bouts. Calibrate **distance-scale λ separately for each array from only earlier 15-bout sources**, common pooled across original bees for that array, from a fixed candidate grid `{0,0.25,0.5,1,2,4}` **per metre**, tie-break to smaller λ; never tune λ on final five bouts.
- `Mgeo` = per-bee stationary source flower prior × `exp(-λ d(B,C))`, positive probability across the physically available 3 alternate flowers, normalized.
- `Mtransport` = **the same Mgeo destination distribution** × `exp(κ cosθ(A,B,C))`, where **κ=1.0**, frozen *from the entirely different Stage 6 Pasquaretta 2019 dataset*, is **never re-estimated** from this 2017 dataset (and the 2017 Stage9 heldout records never change a prediction coefficient). The turning cosine is dimensionless and therefore directly portable across metre scales. 
- Primary: per-bee **heldout proper negative log loss** for *actual triplets* in all three arrays. Aggregate first by each bee within each array, then by original colony within each array; **six colony×array means**, with original biological replication ceiling **two independent colonies**. Report **29 bee identities×3 array cells** with >=5 eligible final-five-bout triplets, source counts, per-array direction of gain and heldout ΔNLL `Mgeo−Mtransport`. Predeclared gate **≥20 eligible bees per array, both colonies represented, ≥100 real heldout triplets per array**; otherwise no inference for that array, no cherry-picking.
- Conditional negative control: **199** shuffles, fixed seed **20261029**, reallocating incoming A only within `(bee, current flower B, source array)` on genuinely heldout records, preserving physical C and all source day/bout identity, no model refits. Source support gate ≥100 exchangeable triplets per array and ≥10 bees with ≥5. Use one-sided `(1+#null gain≥real gain)/(200)`, and report source array-specific successes/failures, not one pooled post-hoc p.
- The experimentally changed physical arrangements are **not randomized in order**: all source bees experienced arrays 1→2→3 and 3D landmarks differ too. Thus even positive transfer cannot identify a causal geometry mechanism versus cumulative learning or unrecorded visual constraints. It can at most establish **out-of-sample predictive transport of a fixed orientation rule** across layouts and independent source colonies.
