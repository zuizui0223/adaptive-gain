# Stage17 — Optional first information request, with a physically calibrated cost gradient

**2026-11-11 | PROSPECTIVE DESIGN AND SYNTHETIC TESTS ONLY | NO new real bee trials.** Separate research Draft PR stacked on Stage16 PR94; Stage15 PR93 remains a mandatory-first design and is not modified. No alterations to real Stage9b–13 outcomes, V5/V6 or main.

## The single advance
Stage16 proved that optimal contingent access has an intermediate-cost advantage **only if a subject can decline the first leaf request**. Stage15 hardware design requires a first request in both modes. Stage17 gives the original bee a genuinely voluntary **SKIP / request U / request V** choice. A precommit subject must bind SKIP/U/V *before* the root cue; a contingent subject chooses SKIP/U/V *after* the root cue. Both arms retain an optional second leaf request. The choice to skip is a recorded animal action, never a missing trial or a coder-inferred zero.

The root signal R is presented at the same original clock in both modes. Hidden independent binary R,U,V states are drawn iid WITH REPLACEMENT on every trial (not a finite balanced deck). Correct target bit T=U when R=0, otherwise V; physical target locations are counterbalanced and source-verified, with either target physically accessible at the recorded decision. Leaf request events are source video/sensor-verified, not inferred from the chosen reward option.

## Simplified prospectively randomized 2×3 cost study — wind omitted
Treatments: **contingent/precommit** × **low/medium/high per-leaf imposed source waiting time**. Wind is **not** manipulated in this main study, to avoid spending colony-level replication on a mechanism the Stage11/12 observational data did not establish. A separate wind experiment could follow a positive access effect; do not add wind as a rescue factor here.

The cost intervention is a *source-calibrated device delay for each actual leaf-reveal*, not a chosen value of Stage16's dimensionless utility cost c. Delay tier limits, cue readability, animal welfare, hardware synchronization, maximum trial duration and baseline feeder opportunity must be fixed in an independent blinded pilot **before** animal outcome collection. Original decisions are not delayed in SKIP trials, and the actual fixed observation window begins at the **root presentation for every assigned trial**, so the extra request genuinely removes some opportunity to feed. This does not guarantee the delay maps linearly to utility c, and it can change fatigue and reward exposure. Do not interpret delay as an independently identified cognitive processing cost.

Matched motor procedures: every original animal performs a pre-root act and a post-root act. In precommit mode, the binding SKIP/U/V act is pre-root and post-root act is a neutral acknowledgment; in contingent mode, pre-root act is neutral and the binding SKIP/U/V choice is after R. Different commitment/anticipation and different source action chronology remain unavoidable, even with motor matching.

## SOURCE-ONLY QA example and original unit
Synthetic example 24 nonexistent colonies × 12 fake bee IDs per colony × **48 trials per bee**, total **13,824 MOCK records**. Each bee has three cost blocks of 16 trials, exactly eight contingent and eight precommit assignments per block. Six permutations of low/medium/high cost-block order are balanced two times each within every 12-bee mock colony. Each source treatment cell has eight original trial opportunities per bee. Within each mode×cost block, physical left/right mapping of target 0 is balanced four each. The original R/U/V source worlds are iid uniform **with replacement** even within blocks. Real allocation seed must be generated privately and prospectively, never public QA seed 20261111.

Crucial sample-size warning: 24 colonies is a *software QA fixture* not a justified field recruitment goal; no effect size or colony-variance estimates for this new mechanism are measured.

## One prospective primary and fixed diagnostic endpoints
**Primary**: each original colony's difference-in-curvature contrast of ACTUAL blank-corrected video-confirmed sucrose consumed per fixed root-anchored 30s:
(D_t=overline{Y}_{contingent,t}-overline{Y}_{precommit,t}) within tier t∈{low,mid,high};
(K = D_{mid} - (D_{low}+D_{high})/2).
Compute each bee's contrasts first, then equal-weight bees within each source colony, then equal-weight independent original colonies. If actual C>=12, report two-sided independent-colony Student-t CI/p; else descriptive pilot NO general-effect p. If source between-colony contrast variance zero, report NO_GO rather than a fabricated near-zero p.

**K is a predeclared *shape contrast* (middle versus mean extremes), NOT an estimate of the curvature of an actual physiological cost function**. It may be positive even when all three access advantages are negative; therefore report the three absolute mode advantages as mandatory interpretation checks and do not label K>0 alone an adaptive fitness improvement.

Secondary (ALL pre-fixed, not new primaries): physical first-query SKIP fraction by mode×tier; first requested leaf relevance after R; physically counted first/second leaf requests; actual target correctness/no-choice rate; observed source time at feeder access; source-confirmed real intake at each tier. Do not compare 13,824 mock events as independent animals. Never discard skipped, no-choice or zero-consumption trials.

Failed source identity, source root/leaf mismatch, unrequested second cue, missing or incorrectly timed source delay, or controller-programmed cue selection labelled as animal-origin fails closed. ## Theorem-to-experiment boundary
Stage16 optional-guess model assumes a normalized correctness reward 1, wrong reward 0, perfect leaf recognition, iid fair world bits, and root recognition probability s. Its **maximum pure information-access utility difference of 1/6** at s=1,c=1/3 is not expected measured sucrose or seconds. Do not select the three real delay tiers based on a peak in biological results. Pilot must measure learnability of R/U/V and genuine voluntary SKIP choice; independently calibrate tier source delays and real ingestion measurement. The exact theoretical optional-game frontier is in Stage16 PR94.

Status: mock design only. No experimental animal, colony, behavior, ethics submission or preregistration is claimed; an actual study requires human approval, secret assignment and real original source acquisition.

## Prior-art update before real animal sampling (2026-11-11)
He et al. 2026, bioRxiv DOI 10.64898/2026.09.15.751944, reported costly information seeking by Bombus terrestris in a 192-bee trial-level source. The public code includes a 19,200-trial file with both `Info_Requested` and `Actually_Landed_On_Platform`. In automatically provided free-cue controls, `Info_Requested=1` does not imply a voluntary landing; the actual landing indicator must be used. This source makes **generic costly bee information seeking prior art**. Stage17's still-unmeasured novelty is whether initial R can guide choice between **two differently informative voluntary information sources** in a precommitted vs contingent access treatment. Without independent observation of actual U/V buttons, source device timestamps and learning proficiency, no transfer or direct empirical confirmation is permitted.

## Source-only reward-contingency improvement (2026-11-11, no animals)
To make actual sucrose intake a meaningful reward consequence of target choice, the physically **correct source target bit** T=U if R=0 else V must be assigned a **pilot-calibrated higher sucrose offering** than the incorrect target, with identical feeder geometry, availability and no pre-choice odor/visual leakage. Actual measured intake within 30s is separate from both nominal offered dose and theoretical one-unit correctness utility. The source-device contract now rejects a mismatch between the hidden target bit and the rewarded physical feeder, missing photometric/odor masking or missing/unequal nominal reward calibration. The public source simulator uses **completely fabricated offers of high 50 mg vs low 30 mg**, solely for checksum-free source gate tests; **no real feeder dose or animal consumption has been calibrated**. The reward mapping, gain/time, feeder blanks and target-side randomization must be fixed independently before any real trial data are collected. The original Stage16 theoretical cost c remains an assumption and is not measured by the fake reward levels.
